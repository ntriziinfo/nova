# 未修正3件の修正（2026-10-01）

ユーザーから「未修整の不具合を修正して」と依頼を受け、直前に説明したBUG-001〜003を修正した。未定義ボイス・設定6の裏特化強化案・抽選パラメータは対象外。

## 変更

- **BUG-001：BIG中のネビュラ押し順ミス** — 第三停止が完了して図柄が揃わなかった場合、精算と結果表示の前にハズレへ変換し、今回のAT権利・ストックと確定表示を取り消す。既に獲得した権利は維持する。`aim.result`には内部当選を残し、監査履歴の`manualLineupMiss`と実際の停止順から取りこぼしを追える。右第一停止の2通り、AUTO、高速試算の正しい当選は維持する。変換を繰り返しても結果が変わらず、第三停止前は未精算とする。途中保存から再開した場合も同じ判定を使う。
- **BUG-002：にと・くしゅりの平均値** — `NovaBalance.zoneMean('kushuri_nito', {setting})`が設定別の初期枠とレア役書換を参照するように修正。設定なしでは実抽選と同じ既定の枠配分を使う。通常の特化ストック・旧保存は倍率なし。初当たりの倍率込みを求める場合は`initialBoostActive:true`を渡し、保存済みの倍率が分かる場合は`initialMultiplier`も指定できる。倍率未指定なら現行の倍率分布の平均を使う。実抽選コードは変更していない。
- **BUG-003：逢魔の逆回転音** — 逆回転フリーズの第三停止では通常の`super-nova-stop.wav`を重ねない。通常のSUPER_NOVAは従来どおり一度だけ再生する。抽選、獲得pt、ストック、乱数消費は変更していない。

## 出玉への影響

変更した獲得条件は、BUG-001で押し順を外した場合の誤加算のみ。手動で取りこぼした場合の実獲得は従来の不具合時より減る。取りこぼし頻度は操作に依存するため、その場合の機械割低下幅は固定値にできない。

正しい押し順のAUTOと高速試算は同じ抽選結果・権利を維持する。BIG50ptの払い出し、内部ネビュラ確率、AT初期pt配分、通常・ATの抽選パラメータは変更なし。平均値補助関数は実抽選や精算の計算には使われない。
