# リザルト統一・レア役ボイス（2026-09-28）

全リザルトを初期pt決定ゾーンと同じ「提供キャライラスト＋RESULT／獲得pt」の形式へ統一。既存の完成リザルト画像の参照をやめ、ランプでも使用している原本PNGを独立したimgとして配置する。原本への加工・学習利用なし。

背景はCSSの青／赤。AT終了の12通り均等、通常ゾーン終了の奇数設定赤60%・偶数設定赤40%という既存選択率を維持する。初期pt決定ゾーンは従来の専用区分を保ち、青背景で2人を表示する。

表示枠・キャラ位置と倍率・獲得ptの位置とサイズはリザルト調整から変更可能。旧保存値から表示枠のみ移行し、新しい調整を `nova_result_layout_v2` に保存する。旧設定は削除しない。

画像読み込み中／失敗時もRESULTと獲得ptを即座に表示。キャラ切替や非表示後の古い読み込み完了を無視する。青／赤でキャラ画像を共有し先読みする。

検証：リザルトの色選択・最終加算・遅延／失敗／非表示時の読み込み、AUTO継続と演出待機、既存キャラボイス、新しい激熱条件、共通音量の計37テストが成功。レア役の判定は全6設定で実際のAT／引き戻しモデルを使用して照合。ブラウザーはミュートし、宗介の赤・ととの青・2人の初期ptを目視確認、コンソールエラーなし。
