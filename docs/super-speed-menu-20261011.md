# 超ハイスピードの終了条件（2026-10-11）

超ボタンを押すと、ボタン上部に以下の選択肢を表示する。メニューを開くだけでは開始せず、項目を選ぶと開始する。

| 選択肢 | 終了条件 |
| --- | --- |
| CZまで | CZ・強CZへ移行したゲームの終了後にAUTO停止。前兆では止めない。直接ボーナス・ATに当選した場合も停止。 |
| ボーナス当選まで | ボーナス内部当選・開始を確認したゲームの終了後にAUTO停止。直接ATに当選した場合も停止。 |
| AT初当たりまで | AT確定を確認したゲームの終了後にAUTO停止。AT非当選のボーナス中は継続。 |
| ノンストップ | 従来どおり通常時を6倍速、AT確定後は通常AUTO。引き戻し・特化ゾーンを含むATが終わって通常へ戻ると6倍速へ復帰。 |

- 到達済みの終了条件は選択不可。実行中はメニューの「停止」またはAUTOボタンで停止できる。
- 管理画面の使用許可・単独試打のデバッグ許可を維持する。許可取消・COMPLETE・手動停止後に自動復帰しない。
- PCの筐体ボタンとスマホの操作バーで共通メニューを使い、各ボタンの上へ配置する。画面外にはみ出さないよう位置を補正する。
- 選択状態は遊技履歴や保存データに追加しない。抽選乱数・確率・投入・払い出し・上乗せ・ストックは変更しない。

検証: 超ハイスピード、バックグラウンドAUTO、音声待ち、準備、設定別機械割の関連テスト48件。PC・スマホのメニュー位置、開閉、全4項目の開始・手動停止、デバッグ許可を無音ブラウザで確認。CZ・BIGを指定した実画面でも、到達ゲームの終了後に停止し次BETが発生しないことを確認。
