## 残る3件

### BUG-001：図柄が揃わなくてもAT権利・ストックを獲得

- 対象：初当たりBIG中のネビュラ狙い。
- 右から停止しないと表示上は失敗するが、内部NEBULA当選をそのまま精算する。
- AT権利なしではATを獲得し、既に権利がある場合は特化ストックが増える。
- 実画面の左→中→右で再現済み。今回の検査は実際の `resolveATypeBonusOutcome`・`prepareManualBonusOutcome`・`applyResult` を通し、4通りの誤停止順×権利有無2通り＝8ケースを記録する。右第一停止の2通り×権利有無の正常例も検査する。
- 検査：[nova-bonus-alignment.test.mjs](../tests/nova-bonus-alignment.test.mjs)。
- 関係箇所：`nova-game.js` の停止図柄制御と `applyResult`。`aimAligned` が精算に反映されていない。
- 修正で獲得権利・実際の出玉が変わるため、取りこぼし時の扱いと影響を確認してから本体へ適用する。今回の整理では変更していない。

### BUG-002：初期ゾーンの平均値を計算する補助関数が旧配分

- `NovaBalance.zoneMean('kushuri_nito', {setting})` が、旧共通の50/100pt配分を使っている。
- 実抽選は設定別の初期配分とレア役書換を使い、平均180・190・200・210・220・230ptになる。各設定12,000回の検査もこの平均と整合した。
- 補助関数の値は奇数設定約207.81pt、偶数設定約206.97ptで、実際の設定別配分と一致しない。
- 検査：[nova-duo157.test.mjs](../tests/nova-duo157.test.mjs)。実抽選の検査は成功し、補助関数の検査だけが失敗する。
- 関係箇所：`nova-balance.js` の `zoneMean` 初期ゾーン分岐。
- これは平均値の集計不整合。今回、新しい機械割の試算や変更は行っていない。

### BUG-003：逢魔の逆回転時にも通常の揃い音を呼ぶ

- 旧検査は参照関数のモック不足で止まっていた。補完すると、逆回転時に省くはずの `super-nova-stop.wav` も呼ばれることを確認した。
- 通常時に1回だけ鳴る検査は通る。逆回転の場合の「追加の通常揃い音を鳴らさない」という既存の期待を残している。
- 検査：[nova-super-stop.test.mjs](../tests/nova-super-stop.test.mjs)。
- 関係箇所：`nova-game.js` の `playStopSound`。
- 音声の呼出しをコードで確認した結果。今回、実音の聞き比べは行っていない。演出音の変更も未実施。

## 更新した主な検査条件

- BIG100/150pt、AT初期150pt固定の期待を廃止。BIG50pt、初期ゾーン3G、設定別配分とレア役100/200pt書換を検査。
- 旧3G裏チャレンジを、10G上位チャレンジ・HOLD・次G狙い・レア役保証の検査へ更新。
- 当選したら即特化へ進む期待を、3〜5G前兆→7→ルーレットへ更新。
- 残りATptが0で即通常へ戻る期待を、5G引き戻しの消化後に終了へ更新。
- 通常A/B・天国モードや2000pt以上の減衰は、廃止済みであることを検査。
- とと1回・空2回・裏空500pt保証、7揃い100pt固定、5Gリセット率2/15/30%、裏ギルのテーブル6固定と通過保証を反映。
- CZ点灯は最後の指示どおり第三停止に限定。点灯ゲームのばらつきや保存再現の検査は維持。
- 正常な旧保存データの移行、実払い出し、獲得済みpt/ストックの保存、AUTO、監査記録の検査を維持。
