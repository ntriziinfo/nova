# 引き戻し5G：全レア役で復活確定（v115）

2026-09-10変更。引き戻し5G中は全設定共通で、弱スイカ・強スイカ・チャンス目A/B・弱ノヴァ目・強ノヴァ目・スーパーノヴァ目の復活率を100%とする。旧い試算用の `comebackRare` 指定が残っていても保証を優先する。

|成立役|復活率|
|---|---:|
|全レア役|100%|
|ベル・リプレイ|1%|
|ハズレ|0.1%|

小役自体の成立確率は変更していない。5Gのうちレア役が成立しなければ復活に失敗する場合があり、5G全体の成功100%を意味しない。

通常のレア役は点滅中のキャラの特化を獲得。強ノヴァ目は弱特化なら強特化以上へ昇格、既存の強特化・裏特化は格下げしない。スーパーノヴァ目は裏ギル・裏空・裏逢魔のいずれかを均等に獲得する。

BETでランプ点滅、第三停止の図柄停止後に当選を告知、次BETから獲得特化へ進む。獲得ptでAT復活し、150ptの追加配布は行わない。ATレベル、爆発チャレンジ使用済み状態、保存からの復帰を維持する。

## 5G全体の復活率

理論値。各役の成立率と復活率の積の合計を q とし、`1 - (1 - q)^5` で計算。

|設定|1G成功率|5G成功率|
|---|---:|---:|
|1|3.4575%|16.13%|
|2|3.5106%|16.36%|
|3|3.5636%|16.59%|
|4|3.6167%|16.82%|
|5|3.6698%|17.05%|
|6|3.7229%|17.28%|

成功時の抽選率は全設定100%でも、小役成立率の設定差により5G全体の復活率には差が残る。

## 機械割の扱い

変更後の機械割・30,000Gの＋10,000pt到達率は未集計。試打台の機械割欄は「未集計（変更前○%）」と表示する。従来の機械割数値は [v114の試算](comeback114-report.md) の履歴であり、v115の実測値ではない。今回、通常・ATの小役確率、初期150pt、特化ゾーン性能、爆発チャレンジの抽選・恩恵は調整していない。

## 確認

- 関連23テスト合格。全7レア役 × 全6設定 × 残り1〜5Gの210条件について、保存復帰後でも必ず復活することを確認。
- ベル・リプレイ1%、ハズレ0.1%の当否境界、強ノヴァ以上の昇格、ATレベル・爆発状態の継承を確認。
- 変更前コードと比較し、通常・AT・引き戻し中の小役成立確率、特化の設定値、爆発ルールが一致することを確認。
- HTML・JavaScript構文と配信ルートを確認。
- 参考として実行した旧 `nova-at150.test.mjs` の「段階成功率の増加・2000pt以降の減衰」テストは不合格。この期待値は過去の仕様で、変更前コミットでも宗介40%に対して「50%より大きい」、減衰なしに対して「係数0.01」を要求していた。今回の変更による不具合ではなく、関連23テストには含めていない。
