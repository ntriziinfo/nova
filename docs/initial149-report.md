# くしゅり＆にと 共通初期ゾーン（v149）

2026-09-28。初期ptを決める3Gの演出を、くしゅり・にとの2択から、2人で1つのゾーンへ変更。

## 進行

- 1G目：にと（茶髪・白い帽子）。
- 2G目：くしゅり（ピンク髪）。
- 3G目：2人を並べて表示。
- 第一停止で下から跳ね、第二停止でさらに高く、第三停止で大きく跳ねて＋50／＋100ptを表示。
- 停止ボタンを押した瞬間ではなく、リールの停止完了に連動。AUTOでも同じ3段階で進行。
- 最終Gの上乗せ表示後、2人のリザルトを表示してATへ。結果画面、リセット、FAST・SPEED開始時には動画を停止。
- ゾーン選択時と消化中は2人のランプを点灯。通常特化のキャラ抽選・リザルト設定示唆は従来どおり。

## 素材

提供された `star_particle_01.mp4` を変更せず保管し、黒背景をアルファへ変換したVP9 WebMを別ファイルで作成。10秒・1280×720・30fps。ゾーン開始時から3Gを通してミュートで連続ループし、各BETでは再生位置をリセットしない。

光の明るさからアルファを作り、黒背景に合成されていたRGBを補正して黒い縁を軽減。変換式とSHA256は `assets/media/nova/star-particle-01.source.json` に記録する。キャラ画像は提供PNGを無加工の別々のimgとして表示し、CSSで拡大・移動する。提供素材を学習・生成用途に使用しない。

## ptと保存互換

初期ptはv148と同じ、3G合計150～300pt・平均200pt。毎G＋50pt（2/3）／＋100pt（1/3）と同じ分布の内部計画を使用。動画とアニメーションは抽選・加算を行わない。通常特化・とと／空／裏空の7揃い100ptとネビュラリセット率も変更しない。

v148のくしゅり／にと途中セーブは、決定済みの初期pt・3G計画・消化G数・獲得済みptを保持して共通ゾーンへ移す。v131の旧初期演出は従来の互換処理を保持。
