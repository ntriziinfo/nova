# 小役統合後の通常・高確・ATの再配分（2026-09-30）

ユーザーの「反映」の指示により採用。チャンス目削除で失った抽選をスイカ・弱ノヴァへ再配分した。機械割は試算値であり、保証ではない。設定6の＋1万pt到達率24.4%も含め、下表の案をそのまま実装する。

## 採用した変更

- チャンス目A/Bの出現枠をスイカに統合。旧弱スイカ＋強スイカ＋チャンス目A/Bを新スイカとする。弱ノヴァと強ノヴァの出現率は維持。全状態へ適用する。
- 通常時のCZ当選・通常高確移行、CZ中の勝利書き換え、準備中の当選、ATの直乗せ・特化・ルーレット昇格・レア役上位チャレンジ抽選を、削除前の出現率で加重平均してスイカと弱ノヴァへ引き継ぐ。
- 通常低確／通常高確のCZ抽選は別に算出し、その後に設定別の係数で微調整。強ノヴァのCZ確定・強CZ優遇は既存のまま。
- ATの低確／高確も別に再配分。強ノヴァの特化獲得100%→40%で減る抽選分も共通特化抽選へ振り分け、払い出し速度の変更を含めて調整。

## 指定条件

- 通常ATは8pt／15ptベルをベル内部で50：50。純増5pt/G。上位ATの通常消化は15ptベルのみ、純増8pt/G。
- スイカ・弱ノヴァのAT高確移行率15%。AT高確10G保証、保証後リプレイ5%転落。
- 強ノヴァは直乗せのみ20%／特化のみ20%／両方20%／この上乗せ抽選の非当選40%。別枠のレア役上位チャレンジ抽選は維持。
- 上位ATの直乗せ当選時ptは通常の1.5倍。特化ゾーン内部の上乗せ性能は据え置き。
- BIG50pt、初回ネビュラ期待度52%／上位BIG80%、引き戻し5G合計20%、上位チャレンジ初回50%／通常65%。
- 出陣、差枚2400ptチャレンジ、設定5/6の既存減算区間、初期ptの基礎配分、ゾーン保証は維持。小役構成の変更による初期ゾーンの実平均の差は試算に含む。

15ptベルのナビ1に7、ナビ2・3にベルの図柄を追加。実際の停止図柄も同じ配置にし、AUTO・保存再開へ対応。中リールの3番・5番の図柄位置を交換し、中リールの7停止時に下段リプレイが重複して揃う表示を防ぐ。配列内の図柄数・抽選確率・払い出しは不変。
