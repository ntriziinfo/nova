## レア役ナビ

同じimgのsrcを黄色の数字からレア役の記号へ変更したとき、読み込み完了まで古い描画内容が残る場合があった。変更前に画像を非表示にし、新しい画像の復号完了後に表示する。先に始めた古い読み込みが後から完了しても、現在のナビを表示しないように要求番号を照合。

配置調整のプレビューを開いていても、ナビのない回転中に黄色の数字を挿入しない。ベル押し順・AUTOの停止順・レア役の色と強弱抽選は変更しない。

## 初期ptゾーンBGM

提供 `audiostock_862200.wav`（194秒、48kHz、24bit、ステレオ）を原本と同一のまま保管。再生用に全区間を192kbps MP3へ変換し、約55.9MBから約4.7MBへ軽量化。切り取り、ノーマライズ、音量加工はしていない。SHA256と変換条件を `assets/media/nova/initial-duo-bgm.source.json` に記録。

くしゅり＆にとの初期ptゾーン開始時から既存BGMプレーヤーで再生。BGM音量・マスター音量・ミュートに連動。3G中は同じ再生位置を保ち、各Gのpt表示中も再生を続ける。リザルト移行で停止し、その後は通常ATのRUSH曲へ戻る。長時間停止している場合はゾーン中のみループ。旧くしゅり／にとの途中保存にも対応する。確認用ブラウザーはプロセス全体をミュートし、原本を学習へ使用しない。

## CZランプ

点灯順：くしゅり → にと → 宗介 → とと → うらぴ → ギル → 空 → 逢魔。

最初の2人は導入の点灯段階として追加し、旧6人の最終期待度（宗介1%／とと5%／うらぴ30%／ギル60%／空80%／逢魔100%）と当落抽選を保持する。通常の15～20G CZでは、最初のGの第一・第二・第三停止でくしゅり・にと・宗介。以降の進行も第一・第二・第三停止へ順番に振り分ける。

表示用8段階と抽選用6段階を分け、第三停止時点の進行・全員点灯で終了するゲーム数を以前と一致させる。失敗CZで逢魔を点灯しない。レア役の成功書き換え・虹告知・第三停止の確定音は従来どおり。第一・第二停止で新規点灯した場合も、そのGの第三停止は点灯成功として扱い、誤った失敗音・リール暗転を防ぐ。
