# 宗介・ギル・裏ギル：小役突破方式

共通テーブルを各1/7で選択。最初のGで初期額を表示・確保し、残りの段階は小役成立で必ず突破、ハズレで終了。最高到達額のみATへ加算。⑦は初期表示＋1回挑戦の計2G。進行中の保存済みテーブルは維持する。

1. 50 / 100 / 200 / 300 / 500
2. 50 / 50 / 500 / 500 / 1000
3. 100 / 200 / 300 / 500 / 1000
4. 100 / 100 / 500 / 1000 / 2000
5. 200 / 300 / 500 / 1000 / 2000
6. 300 / 500 / 1000 / 2000 / 3000
7. 50 / 2000

専用小役抽選は1回の乱数でリプレイ・ベル・ハズレを決定。標準小役合算率は宗介70%、ギル95%、裏ギル98%。内訳は合算率の70%がリプレイ、30%がベル。既存カスタム設定は維持。成立役への追加当落抽選や2000pt到達抑制はこの3ゾーンでは行わない。

標準単体上乗せ期待値：宗介740.69pt、ギル1443.18pt、裏ギル1560.20pt。通常時等を含む機械割は未再測定。
