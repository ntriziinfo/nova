# 初回起動・回転途中復帰・設定表示の修正

## 修正内容

- 初回起動で保存データがない場合の例外を修正。保存済み環境と同じ順序で設定移行を完了させ、空・裏空などに旧確率が残らないようにした。初回に設定したカスタム値も次の起動で初期値へ戻さない。
- BETで決まった成立役、結果、停止図柄、押し順、停止済みリール、着地待ちの図柄を保存。再読み込み後は追加BET・再抽選なしで残りリールを停止できる。AUTOは従来どおり停止状態で復帰する。
- 第三停止から決済までの間に再読み込みしても未決済の結果を一度だけ反映する。払い出し途中の保存を抑え、結果反映と未決済回転の削除をまとめて保存する。
- 設定画面の機械割を承認済みv173試算値へ更新し、3万G・試行数・コンプリート停止込みの推定値であることを明記。
- BIG関連の読み取り専用項目を実際の規定払い出し50ptへ統一。

抽選エンジンの小役確率、上乗せ率、保証、初期pt、減算区間のパラメータは変更していない。初回起動時の移行漏れを直すことで、設定が既存の承認済み仕様に一致する。表示した機械割は既存の試算結果であり、この修正について新たな機械割推定を行った数値ではない。

## 検証

- 構文・静的配信設定の検証に成功。
- 保存・復帰などの回帰テストを9件追加し、全件成功。初回／保存済み起動、カスタム設定、獲得済みpt・ストック、停止順、着地待ち、通常・CZ・AT・BIGの一度だけの決済、リプレイ、0G消化を確認。
- 全体テスト475件：403件成功、72件失敗。失敗したテスト名は修正前の既知72件と完全一致し、新規失敗なし。旧仕様の期待値や不足したモックを持つ既存テストは今回変更・無効化していない。
- 現行v173の全設定30,000Gの試作・実装一致テストも成功。
- 無音・管理サーバー非接続のChrome検証台で、通常ベルのBET直後／第一停止後の再読み込み、ATベルのBET直後／第二停止後の再読み込みを実施。通常ベルは1G・差枚−3→＋12、ATベルは32G維持・差枚45→60・AT残り175→160となり、払い出しが一度だけ反映された。
- AUTOで準備・初期pt決定・AT・特化ゾーンまで継続することを確認し、検証タブを終了。

この変更より前に未保存のまま失われた回転結果は、保存されていないため復元できない。端末の保存領域が使えない場合や、タブを複数開いて同じ台データを同時操作する場合の競合は、この修正の対象外。
