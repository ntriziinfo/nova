# 出陣ストックのボイス・連続特化リザルト

- 獲得済み特化ストックの7狙いは、そのキャラに登録されたボイスを使う。裏ゾーンも同じキャラに対応する。未登録キャラは従来の共通ボイスから選ぶ。
- ストック消化の最初の実ゲームは `zoneStartFlow` を参照する。空・ととの7狙い、ネビュラ狙い、継続ボイスが直前のAT状態に引っ張られない。
- 初当たりや未決定のキャラルーレットは従来のランダム選択を維持する。
- 各ゾーン終了時の `award` を合計し、連続特化のリザルトに今回分と合計を表示する。例: 空300pt→とと500ptなら、後者は今回500pt・合計800pt。
- 合計は特化ゾーンの上乗せptのみ。ベル払い出しやAT全体の払い出し累計は含めない。準備・7狙い・次の特化が続く間は引き継ぎ、通常ATへ戻ると区切る。
- 表示用の合計は `normalState.zoneResultChain` に保存し、リザルトカードにも固定する。再描画、再読み込み、逢魔0G終了、宗介・ギルの遅延リザルトで重複加算しない。
- 抽選・払い出し・上乗せ・ストック消化は変更しない。最初のゾーンで従来消費していたボイス用乱数1回を維持し、後続のゲーム抽選をずらさない。

検証: ボイス・連続集計・AUTO・逢魔演出・保存復元の関連テスト。無音ブラウザ検証は `research/sortie-debug-20261001/zone-chain-qa.mjs`（PC/390px幅、突入と初回ゲームの再生対象、300+500=800pt、再読み込みとAUTO）で実行する。
