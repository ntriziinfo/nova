# 直乗せを50pt固定の宗介ゾーンへ置換

## 2026-10-15 承認済み変更

上位ATだけは、固定宗介への置換を行わず、同じ当選頻度で50ptを即時加算する。画面とSEは既存の直乗せ演出で第三停止時に表示・再生する。通常ATの50pt固定宗介、別枠の特化ゾーン当選と同時当選、到達確定後の抽選停止は維持する。変更前のセーブに残る獲得済み固定宗介は消さず、従来の流れで受け取る。

各設定1万G×300回、差枚＋19,000pt停止・MY停止なしの同一シード予備比較で、機械割差は設定1から順に＋0.32／−0.38／−0.57／−0.08／−0.27／−0.80ポイント。試行誤差を含み、機械割の完全維持を保証するものではない。ユーザーへ提示し「この内容で反映する」の承認を得た。抽選頻度・50pt・抽選時の乱数消費は同じだが、固定宗介に伴うゲーム進行が減る。

承認済みの比較結果・条件・全設定の再現用サンプルは [JSON](upper-direct50-20261015.json) に保存。以下は2026-10-14時点の採用記録。

採用内容：通常AT・上位ATの両方。ユーザー承認「上乗せ額の平均を保つよう頻度を減らして反映」。元の当選判定後に、従来の平均上乗せ額÷50の確率で固定宗介を獲得する。通常の特化抽選、初当たり、上位突入、設定別モード抽選は変更しない。

レア役当選→通常の3〜5G前兆→第三停止で特化告知→7を狙え→ルーレット→宗介→50pt表示→継続失敗→宗介50ptリザルト。50ptは終了時に一度だけAT残ptへ加算し、当選ゲームでは即時加算しない。固定ルートではルーレット昇格・ゾーン内増額を行わない。別口の特化当選は同時当選を含め保持する。

通常ATで旧直乗せ当選を残す割合は弱レア37.1311%、強ノヴァ52.28%。上位ATでは従来の1.5倍平均に対応し、それぞれ55.6966%、78.42%。いずれも50pt固定。これらは「レア役成立時の総当選率」ではなく、旧直乗せに当選した後の残存率。

内部では前兆・待機ストックに `fixed50_sosuke`、突入待機に `pendingFixed50`、ゾーン滞在に `fixed50Zone` を保持する。表示と音源は既存の宗介を使用。通常の宗介抽選からは固定ルートを選ばない。旧セーブの通常宗介も通常のまま復元する。
