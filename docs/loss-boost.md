# 差枚−2000pt以下の上乗せ優遇（2026-09-08）

全設定共通。実投入を差し引いた遊技開始からの差枚が−2000pt以下なら、AT中の直乗せ・弱ノヴァによる新規特化ゾーンの当選率を1.5倍（100%上限）にする。−2000ptを上回ると直ちに解除。フラグを別保存せず、共有エンジンに渡される累計差枚から毎回判定する。通常回転・高速回転・保存再開で共通。
