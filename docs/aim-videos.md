# とと・空・裏空 狙え動画

- 共通色振り分け: 青60%、赤35%、レインボー5%。
- 色別当選率: 青20%、赤80%、レインボー100%。合算45%。
- BET時に図柄・色・成否を抽選。色や成否を停止時に再抽選しない。
- 7/nebulaの比率は既存の各ゾーンhit/reset設定の比率。7獲得pt振り分け、nebulaの10ptと5Gリセットは維持。
- 色別信頼度を保証するため、この3ゾーンの2000pt到達時の7当選取消は廃止。nebula比率への既存の2000pt補正は維持。
- シャッターと同じランプ欄の座標で再生。BETから第三停止押下まで無音ループ。リールを覆わない。
- 強制デバッグ当選はレインボーで表示。強制ハズレは青。統計からは除外。
- 動画はユーザー確認済みの青/赤/虹の6本。人物なし。原本は変更せずコピー。
- この変更で機械割も変わる。機械割の再調整・測定は本変更には含まない。

## 成立演出・音声

- 青・赤・虹の狙え発生時に対応SEを1回再生。ループなし。
- 赤7成立の第三停止でseven-win.mp4とseven-win.wavを同時再生。動画は無音・ループなし。
- 動画の再生開始から3秒間は次BETと高速開始をロック。最終Gのリザルトもこの間は待機。
- 次BETで動画は消えるが当選SEは最後まで継続。連続当選でも前のSEを切らない。

## 狙え停止順

- 内部抽選・恩恵は維持。右第一停止の場合だけ7/nebulaが中段揃いする。
- 右→中→左はハズレ時のみ第三停止で外れる。
- 右→左→中は左中段で2確。ハズレ時は左中段を外す。成立動画は全リール停止後。
- 左/中第一停止は第三停止で外れ、成立動画を出さない。AUTO/全停止も右から。
- ランプは読み込み中の台サイズを使って保存位置を書き換えない。

## 停止完了・ハズレナビ

- 狙え動画は第三停止ボタン押下では消さず、全リールの停止完了で消す。成功動画も停止完了後。
- 内部ハズレの50%に狙えナビを出し、残り50%は動画・狙えSEなしの通常ハズレ停止。BETで一度だけ選択。内部当選はナビあり。
- 内部色抽選と当選率は維持。ハズレナビ間引きにより、表示された青の期待度は約33.3%、赤は約88.9%、虹100%となる。

- ナビありで図柄が外れた場合、停止完了後に動画をモノクロ化しouma-fail.wavを1回再生。650ms表示を確保してから最終リザルト/AUTOを許可。次BETで解除。
- nebula成立も7と同じ第三停止完了・3秒ロック。nebula-win.mp4 / nebula-win.wavを同時再生し、音声は次BETでも継続する。

## 7揃い最低1回保証

- とと・空・裏空はsevenHitsで7当選回数を保存。ゾーン突入時に0へ戻す。
- 未当選のまま最終Gでハズレた場合、レインボー7当選に置換。既存の上乗せ額振り分けを使用。
- nebula当選時は通常どおり5Gリセットし、未消化保証を維持。7当選後は追加保証なし。
- 押し順条件は従来どおり。内部当選を保証し、左・中第一停止での図柄揃いは保証しない。
- 平均獲得の計算も保証を加算。各1000ゾーンの検証で7当選0回は全種0件。機械割の再測定は未実施。
