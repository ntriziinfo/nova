# とと・空・裏空 狙え動画

- 共通色振り分け: 青60%、赤35%、レインボー5%。
- 色別当選率: 青20%、赤80%、レインボー100%。合算45%。
- BET時に図柄・色・成否を抽選。色や成否を停止時に再抽選しない。
- 7/nebulaの比率は既存の各ゾーンhit/reset設定の比率。7獲得pt振り分け、nebulaの10ptと5Gリセットは維持。
- 色別信頼度を保証するため、この3ゾーンの2000pt到達時の7当選取消は廃止。nebula比率への既存の2000pt補正は維持。
- シャッターと同じランプ欄の座標で再生。BETから第三停止押下まで無音ループ。リールを覆わない。
- 強制デバッグ当選はレインボーで表示。強制ハズレは青。統計からは除外。
- 動画はユーザー確認済みの青/赤/虹の6本。人物なし。原本は変更せずコピー。
- この変更で機械割も変わる。機械割の再調整・測定は本変更には含まない。
