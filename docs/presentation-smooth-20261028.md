# 演出表示の整理・負荷対策（2026-10-28）

## 責務

- `nova-presentation-resources.js`: ループ動画の再生要求の重複防止、表示終了後の遅延play完了の抑止、再生失敗の上限付き再試行、タブ非表示時の停止・復帰、画像の先読みジョブ管理。
- `nova-aim-presentation.js` / `nova-sortie-aim.js` / `nova-upper-at-background.js`: 各演出の表示条件・位置・素材を所有。共通リソース処理にループ動画再生を委譲。
- `nova-results.js`: リザルトの内容・画像・配置。獲得数や示唆選択は変更せず、表示済み画像のdecode待ちと全員画像の一括待ちを除去。
- `nova-impurity-hint.js`: 穢れ示唆・解放BBイラスト。解放イラストの位置計算を描画フレーム単位でまとめる。示唆は画像ロード後に表示時間を開始し、取り消し済みのロード完了は無視する。

## 読み込み方針

狙え動画はデスクトップでmetadata、コンパクト表示でnone。表示時に再生する。リザルト画像は低優先度の先読みジョブを最大2つずつ進め、表示対象は高優先度へ切り替える。ネットワーク待ちが長いジョブは8秒でキューを解放する（通信自体の中断ではない）。表示条件や当選情報は先読みしない。

当選時のSE・ボイス・入力ロックに連動する単発動画は従来の開始・終了処理を維持。ゲーム抽選、乱数消費、払い出し、ストック、待ち時間は変更なし。

## 検証

- 関連106テスト通過。画像decode未解決、遅延play完了、非表示タブ復帰、再試行上限、示唆ロード前のタイムアウトを検証。
- HTML/JS/素材参照のチェック通過。
- 無音Edgeヘッドレス。実jagページのリザルトと、分離した演出検証ページのスーパーノヴァチャレンジ動画・緑示唆を確認。外部APIは遮断し営業データを変更していない。ページエラー0、動画readyState4・再生時間増加を確認。
- 起動時の全量先読み指定の動画数: 同じ画面条件で変更前16、変更後2（全video要素は22）。通信量・FPSの改善率を測定したものではない。
- 追加で調べたbackground-auto/mobile-loadingの3失敗はHEAD版でも再現する既存のテスト不整合。対象外の既存変更は含めない。

証跡は親workディレクトリの `presentation-smooth-20261028/` と `presentation-smooth-20261028-baseline/`。
