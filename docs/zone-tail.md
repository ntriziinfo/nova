# ゾーン単体2,000pt以上の抑制（2026-09-08）

全設定・9ゾーン共通。そのゾーンの累計上乗せに次の上乗せを加えると2000pt以上になる抽選を、従来の1%にする。獲得済みptを切り捨てない。新しいゾーンでは累計をリセットし、nebulaによる延長・再読込では保持する。

- 段階式：次の段階が2000pt以上になる突破に1%判定を追加。失敗時は現在までの最高到達額を精算。
- 7揃い系：累計2000pt以上になる7当選を1%にする。到達後はnebulaリセット率も従来の1%。
- ノヴァ系：有料Gで累計2000pt以上になるノヴァ当選を1%にする。
- 逢魔フリーズ：次の最大上乗せ（表100pt・裏200pt）で2000pt以上になる場合から、BET時のフリーズ継続率を1%にする。発生確定済みの無料揃いは必ず実行・加算。
- 明示的に図柄を強制するデバッグは通常の上乗せ抑制を迂回する。通常の強制ゾーン突入後の自然抽選には適用する。

差枚に応じたAT制御は継続。こちらは差枚ではなく「1ゾーンの累計上乗せ」で判断する別の制御。ゾーン選択率・裏昇格率3%は変更しない。
