# 特化ゾーンの加算pt表示

宗介・とと・うらぴ・ギル・空・逢魔・裏ギル・裏空・裏逢魔の上乗せを、直乗せと同じリール全面の透過文字で表示する。

- 第三停止の図柄停止完了で表示。押下だけでは表示しない。
- 表示するのは今回新たに確保した差分。100ptから350ptなら「＋250pt」。同額の段階通過・失敗・ゾーン合計のATへの移し替えでは再加算表示しない。
- 初回の基準pt確保、初期ATの50pt刻みの演出、ネビュラの＋10pt、ノヴァ・0G連も対応。
- 次の有効なBET、フリーズ継続BET、リセットで消去。最終加算がリザルトに隠れる場合だけ、加算表示開始から最低1秒待つ。既存の当選動画の3秒待機は維持。
- ゾーン固有の当選音を維持。直乗せ専用WAVをゾーン音に重ねて再生しない。
- 抽選・pt会計の変更なし。加算分は監査ログの `zoneAward` に記録。
