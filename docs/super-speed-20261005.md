# 超ハイスピード（2026-10-05）

- AUTO横の金色の丸い「超」ボタン。スマホ操作バーにも追加。
- VERTEXの各NOVA台で「超ハイスピード ON/OFF」を管理者が切り替える。初期OFF。
- 管理画面から起動した台は既存の5秒間隔のコマンド確認から使用許可を取得。台側の保存設定・URLでは許可しない。
- OFFまたは通信失敗でAUTO停止。応答が途絶えた場合も最後の許可から15秒で失効。途中の回転は最後まで確定する。
- 通常AUTOの回転・停止・結果待ち・次BETの待ち時間を1/6にする。描画時間が積み重ならないようBETからの期限で進行。高速中は連続リール画像のDOM生成を省略。
- CZ・強CZ・AT未当選のボーナスも継続。AT突入、ボーナス中のAT獲得、準備中のAT保証で停止。終了済みボーナスの過去の当選は判定から除く。
- 高速開始・停止・許可確認で抽選を呼ばない。実際のBET・停止順・結果確定・払い出しは既存AUTOと同じ処理。抽選エンジン、役確率、pt仕様は変更しない。
- 遅れた前の回転の自動停止予約は次回転に適用しない。

## 単独試打のデバッグ許可（2026-10-06）

- デバッグメニューの先頭に「超ハイスピード使用許可：ON/OFF」を追加。許可後、筐体またはスマホ操作バーの「超」で開始。
- 管理接続も遊技セッションもない単独試打だけで利用できる。管理画面から起動した台では無効で、管理側の許可を優先する。
- 許可はページ内だけで保持し、再読み込みでOFF。許可をOFFにすると超ハイスピードを停止する。AT確定時の停止条件は共通。
- 許可切り替えは抽選・払い出し・速度倍率に影響しない。
- 追加検証：関連テスト57件成功。無音ブラウザでPC・390pxスマホの許可ON→開始→停止、再読み込みでOFF、管理接続時のデバッグ許可不可を確認。ページエラーなし。

## 検証

- 関連テスト54件と追加の音声・狙え・ストック・手取りptテスト50件（重複あり）成功。
- 管理側17件：管理者認証、型検証、NOVA限定、ポーリングでのON/OFF、古い遊技スナップショットからの上書き防止、リセット・ローカルサーバー再起動後の保持を確認。
- 無音ブラウザ：管理UI ON/OFF、CZ継続、BIGネビュラ当選後の停止、通信失敗時停止、既にAT中の開始不可、PC/390pxスマホ表示。
- 同じベルを指定した10GのBET間隔：通常AUTO平均1,277ms、超平均238ms（実測5.37倍）。設定は6倍、実際の速度は端末の描画・保存負荷による。
- QAは合成データのみ使用。本番台の設定・遊技状態・使用許可は変更しない。
