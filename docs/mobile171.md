# スマホ表示・空のネビュラ狙え（v171）

- 画面幅1,024px以下でスマホ表示。縦画面では筐体全体を幅に合わせ、短い横画面ではランプ・リールを中心に表示する。画面回転時に再計算し、ノッチ・ホームバーの余白を確保する。ブラウザーのピンチ拡大は制限しない。
- 下部にBET・左／中／右停止・AUTOを固定表示。元の操作ボタンにクリックを渡し、押し順・演出待機・停止禁止・AUTOの処理を共用する。通常の操作ロックと逢魔の逆回転待機も反映する。
- グラフ・役カウンター・音量パネルは画面内に収めてスクロール可能にする。PC用の拡大率、横位置、リール・ランプ配置の保存値は上書きしない。スマホ表示中は配置編集用ボタンを非表示にする。
- 空・裏空のネビュラ狙え表示BETに専用音源を登録。初当たりBIGのランダム選択にも追加。詳細と原音保全の記録は `character-voice-audio.md` および `sora-nebula-voice-normalization171.json`。
- 抽選確率・上乗せpt・設定別制御には変更なし。

検証：Chromiumのタッチ端末エミュレーション（360×780、390×844、430×932、768×1,024、844×390）。全サイズで横はみ出しなし、操作ボタン44px以上、グラフ・音量・役カウンターの開閉、手動の逆ハサミ停止、AUTOの継続／解除、逢魔ロック、PC表示への復帰時の保存値保持を確認。新音源のHTTP取得とブラウザーのデコードを確認。実機iPhone／AndroidとSafariは未検証。全確認は無音、管理サーバーへの書き込みを遮断した独立セッションで実施。

再現用：`node research/release-171/browser-qa.mjs`（ローカルURLは4175ポート。`QA_URL`で公開版を指定可能）。ボイス関連18件とAUTO関連6件の既存テスト、HTML構文、静的配信設定が成功。
