# リザルト画像待ちの暗転を解消

従来のNovaResults.showはリザルト時に2.6～2.8MBのPNGを新しく読み込み、その間、画像と獲得ptを隠して黒いカード背景だけを表示していた。画像応答を止めた独立ブラウザーで、黒背景・画像非表示・pt空欄の状態を再現した（research/result138/baseline.json）。

12種類の元画像をページ初期化時に先行読み込み・デコードし、リザルト時にはその画像を同期的に差し替える。元イラストは加工しない。通信待ちや画像エラー時にも、RESULT・対応キャラ・今回の獲得ptを即時表示する。別キャラや別色の古い画像は出さず、遅れた応答や非表示後の応答で画面が戻らないよう既存の要求番号を維持する。画像エラー後の次回表示では再取得できる。

第三停止、最終上乗せ表示、狙え成功動画の3秒待機、リザルトのアイキャッチ再生完了までのBETロックは既存どおり。抽選・払い出し・ゲーム数は変更しない。

検証:

- 読み込みを意図的に止めても、黒い空欄にならずRESULTと現在の750ptが見える。
- デコード済み画像の再表示は同期処理内に完了。隔離ブラウザーで処理約1ms（処理時間であり実機全体の表示遅延保証ではない）。
- 別キャラ・青から赤への連続切替、古い画像の遅延応答、hide後の応答、404時のpt表示継続を確認。
- リザルト・アイキャッチ・AUTO・狙えに関する31テスト合格。従来の停止順試験にあった隣接行への依存を、停止→全停止判定→演出の順序確認へ更新。停止関数自体は未変更。
- 無音の独立ブラウザーでギル・空・逢魔と引き戻し失敗後の4ケースでリザルトからAUTOが再開し、アイキャッチ途中のBETがないことを確認した。逢魔では実際の逆回転フリーズも2回経由した。

再現: node research/result138/qa.mjs。AUTO確認: NOVA_QA_CASE=ouma,giru,sora,comeback を設定し node research/auto130/qa.mjs。結果はresearch/result138/qa.jsonおよびresearch/auto130/qa-ouma-giru-sora-comeback.json。
