# ATレア役ナビ・ラダーpt表示・AUTO速度

通常ATのBET時に、成立役に対応する記号を各リール上部へ表示する。既存の黄色ベルナビと同じ位置調整を使用し、停止したリールから消す。AUTOも同じ表示を使用する。記号は押し順を指定せず、黄色ベルナビのランダム押し順とBET音は従来どおり。

|役|色|表示|
|---|---|---|
|弱スイカ|緑|！|
|強スイカ|緑|！／！！ 各50%|
|チャンス目A|紫|！|
|チャンス目B|紫|！／！！ 各50%|
|弱ノヴァ目|赤|！|
|強ノヴァ目|赤|！／！！ 各50%|
|スーパーノヴァ目|赤|！！|

チャンス目Bを紫「！！」の対象とする回答に基づく表示上の分類。チャンス目A/Bの内部性能、小役確率、払い出し、AT抽選は変更しない。通常時・CZ・BIG・上乗せゾーン・初期pt演出・引き戻し・裏ゾーンチャレンジは既存の専用表示を使用する。表示結果を遊技履歴のrareNaviにも保存する。

宗介・ギル・裏ギルのzoneAwardは記録・計算を継続し、リール全面の加算pt画像だけを非表示とする。シャッター・段階・確定pt表示は継続。他の上乗せゾーンと通常ATの直乗せ表示は継続する。

## AUTOの実測

設定3、AUTO間隔0.5秒（既定値）、通常AUTO、音声・映像の再生速度1倍。無音の独立したEdgeで180Gずつ計360Gを測定。役や当選は強制せず、BETから次BETまでの時間を集計した。0G連は回転数へ加算せず、その演出時間は含める。

|開始状態|測定G|所要秒|1時間換算|8時間換算|
|---|---:|---:|---:|---:|
|通常|180|274.45|2,361G|18,889G|
|AT初期pt待機|180|256.18|2,529G|20,235G|

通常開始の標本は全180Gが通常。AT開始の標本は初期待機等5G・特化ゾーン5G・AT166G・通常4G。短時間の速度測定なので、全設定の長期平均や機械割の試算ではない。今回の条件では約2,300～2,500G/時、8時間で約1.9万～2.0万Gが目安。長いフリーズ・確定動画・リザルト待ちの頻度や端末負荷で低下する。8時間換算はコンプリート等で途中停止せず動作を続けた場合。

記録: research/navi136/timing-normal.json、timing-initial.json。再現スクリプト: measure-auto.mjs。ブラウザ検証: qa.mjs、qa.json。色・強弱ヒントの境界とゾーン表示の除外はtests/nova-navi136.test.mjsで確認する。

検証結果: 関連単体テスト11件合格、ブラウザ17項目合格、画面エラー・素材欠落なし。全役の記号、黄色ベル音、AUTO、宗介・ギル・裏ギルの非表示、空の加算表示継続、位置調整プレビューを確認した。
