# 上位ATチャレンジのカウント表示・全キャラリザルト

- 通常AT／上位ATの通常消化中、ランプ上の表示を「上位ATチャレンジまで○○pt」へ変更。次の未消化の累計差枚トリガーと台の累計差枚との差を表示する。AT残ptが0になったことではリザルトを発生させない。
- 金色表示は、実際の累計差枚がトリガーへ到達し、上位ATチャレンジの権利を獲得したときだけ。残AT払い出しptを足した見込みでは金色にしない。到達済みの権利が待機・予約されている間は、BETで差枚が下がっても0pt・金色を維持する。上位ATへの成功確定を示すものではない。
- 実際に差枚トリガーへ到達すると0ptを表示し、上位チャレンジの直前に全8キャラの「有利区間終了」リザルトを一度表示。数値はその時の累計差枚（AT総払い出しとは別）。
- 次のBETで既存の上位チャレンジへ進む。リザルト自体にはBET代・回転数・乱数消費がなく、残ptやストックを消費しない。残pt等のリセットは従来通りチャレンジ開始時。
- 特化・前兆・ボーナス等の途中で到達した場合は、既存の進行を終えてから表示する。特化のリザルトもある場合はそれを先に表示し、次のBET操作で全キャラリザルトへ切り替える（この切替は無消費）。
- 表示済みの差枚ラインを保存。同じ到達点で二重表示せず、次の＋4,800／7,200／9,600ptではそれぞれ表示。リザルト表示中の再読み込みでも同じ画面を復元する。
- 8人の提供イラストは原本のまま個別に表示し、背景・文字はCSS/HTMLで描画。「リザルト調整」の「全キャラ・有利区間終了」から配置を調整可能。

抽選エンジン、確率、獲得pt、払い出し、ストック、差枚トリガーの条件に変更なし。機械割の再調整なし。

検証：関連単体テスト、構文・設定検証、313個の配信素材検証。無音の独立ブラウザで、手動/AUTOの到達と再開、無消費のリザルト切替、再読み込み、次の到達点、390pxのスマホ幅を確認。
