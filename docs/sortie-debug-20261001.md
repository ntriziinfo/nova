# 出陣チャレンジの強制指定

非公開デバッグの「次回転の出目指定」で「ノヴァ出陣チャレンジ（10G・1回予約）」を選び、「次回だけ適用」を押す。次のBETで出陣権利を1個だけ予約し、指定を解除する。

- 突入可能なAT中はそのBETから開始。ボーナス、CZ、初期pt決定、特化、前兆、上位チャレンジ等の進行中は既存の出陣待機処理を使う。
- 通常時は自然当選時と同じAT初期pt決定を経由する。既にある残ptやストックは消さない。
- 予約は通常の保存領域へ入り、再読み込み後も保持する。手動・AUTO・高速回転は同じ予約処理を通る。
- 内部指定値は `SORTIE`。出目として抽選エンジンへ渡さず、既存の出陣抽選に確定デバッグ入力を渡して権利だけ追加する。予約操作では乱数を消費しない。
- 出陣の10G、ストック率の振り分け、ゾーン選択、最低2個の保証は現行のまま。通常の出陣確率・機械割に変更はない。強制使用した試打は通常の機械割検証には使わない。

検証：関連テスト15件、構文・設定・配信素材検査。無音の独立ブラウザで、AT中の1回突入、進行中の再読み込み、特化中の予約保持、通常時の準備移行、AUTOによる10G完走と最低2個のストックを確認。ブラウザエラーなし。
