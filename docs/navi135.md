# ナビ記号素材とベルBET音

緑・紫・赤それぞれに「！」と「！！」を生成。元の数字ナビと同じ横3連の透過スプライト。`assets/design/nova-navi-alert-v1/` の6枚、manifest.json、README.mdに画像・寸法・生成プロンプトを保存。元の生成PNGを無加工で使用。

黄色の1・2・3はベルの押し順案内として継続。今回の記号画像は演出用素材で、発生条件や出現確率の追加はない。

提供された `audiostock_1181985.wav` を `assets/media/nova/bell-navi.wav` に無加工で保存。通常ATのベルナビをBETで表示した直後、同じ処理内で1回再生する。SE音量に連動し、ループなし。手動・AUTO・途中AUTO引き継ぎに共通。ナビ調整用プレビューでは鳴らさない。停止時のベル払い出し音は従来のタイミングのまま。

ブラウザ検証はユーザーの試打とは別のプロファイルを使い、音声出力をミュートする。手動6押し順、AUTO6押し順、途中AUTO引き継ぎの計13BETで、表示と音声再生の差50ms以内、各1回、実デコード成功、ループなしを確認する。非ベル・調整プレビューの再生なしも確認。記録は `research/navi135/qa.json`、素材情報は `assets.json`。
