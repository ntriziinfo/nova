# キャラボイスの音量管理

2026-09-20: 筐体右上の♪ → **ボイス音量（全キャラ共通）** でまとめて調整する。既存の `settings.voiceVolume` を使い、保存済みの設定値を引き継ぐ。マスター音量・全体ミュートも適用し、再生途中の変更はセリフを再開せず即座に反映する。

対象は宗介・空・ギルの押し順、７狙え、ネビュラ狙え、ゾーン開始、継続、よっしゃあ、ボーナス確定、特化ゾーン抽選、NOVA RUSH確定、CZ残り3・2・ラストのボイス。特化ゾーン抽選とNOVA RUSH確定は従来の効果音カテゴリから移した。色別狙えSE・７/通常ネビュラ成立SE・シャッター等の効果音は従来のカテゴリを使う。

## 登録場所

`jag.html` の `CHARACTER_VOICE_SRCS` がカテゴリの一覧。以下の既存一覧へ追加した音源は自動的に含まれ、先読みも行われる。

- `BELL_NAVI_VOICE_SRCS`: キャラごとの左・中・右。
- `AIM_VOICE_SRCS`: 図柄ごとの狙えボイス。
- `ZONE_START_VOICE_SRCS`: ゾーン開始ボイス。
- それ以外のセリフは `CHARACTER_VOICE_SRCS` に登録する。

再生元の設定にかかわらず、登録音源は共通のボイス音量を使用する。URLのキャッシュ用クエリが変わってもカテゴリを維持する。NOVA RUSH確定の動画連動・3秒待機・次BETから3秒フェードは維持し、フェード途中もボイス音量に追従する。

## ノーマライズ方針

**全キャラの音源が揃ってからノーマライズする。現時点では実施しない。** 提供原本・ゲーム用音源の波形を変更せず、キャラ別・ファイル別の追加ゲインは掛けない。今回統一したのは音量の操作系であり、録音ごとの音圧差はそのまま残る。

全員分の導入後にカテゴリ一覧を対象にラウドネスとピークを測定し、共通基準を決めてゲーム用の出力を作る。提供原本は保持する。素材はユーザー提供の著作物として扱い、学習には使用しない。

検証: 共通カテゴリ・再生中の変更・マスター・ミュート・効果音との独立性・確定ボイスのフェードを `tests/nova-voice-volume.test.mjs` で確認。
