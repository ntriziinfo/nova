## 登録場所

`jag.html` の `CHARACTER_VOICE_SRCS` がカテゴリの一覧。以下の既存一覧へ追加した音源は自動的に含まれ、先読みも行われる。

- `BELL_NAVI_VOICE_SRCS`: キャラごとの左・中・右。
- `BELL_NAVI_COMPLETE_VOICE_SRCS`: ベル揃い時のキャラ別ボイス。未登録キャラは宗介を使用。
- `AIM_VOICE_SRCS`: 図柄ごとの狙えボイス。
- `SEVEN_ZONE_VOICE_SRCS`: ゾーンと７狙えボイスの対応。
- `NEBULA_ZONE_VOICE_SRCS`: ゾーンとネビュラ狙えボイスの対応。専用音源を追加したキャラはここへ登録し、ランダム補完から切り替える。
- `ZONE_START_VOICE_SRCS`: ゾーン開始ボイス。
- `ZONE_CONTINUE_VOICE_SRCS`: ゾーンごとの継続ボイス（裏ゾーンは基本キャラへ対応）。
- `OUMA_NOVA_VOICE_SRCS`: 逢魔・裏逢魔限定のノヴァ狙えとノヴァ揃い3種類。
- `RARE_CUE_VOICE_SRCS`: くしゅり・にとのレア役チャンス／大チャンス／激熱。両キャラから等確率に選び、BETで1回だけ再生。
- それ以外のセリフは `CHARACTER_VOICE_SRCS` に登録する。

再生元の設定にかかわらず、登録音源は共通のボイス音量を使用する。URLのキャッシュ用クエリが変わってもカテゴリを維持する。NOVA RUSH確定の動画連動・3秒待機・次BETから3秒フェードは維持し、フェード途中もボイス音量に追従する。

## ノーマライズ方針

2026-09-20: ユーザーの「音量が小さかっただけだからボイスをノーマライズして」という指示により、全員分が揃うのを待つ方針を変更し、現在登録されている25本を処理した。

- ゲーム用コピーを **−12 LUFS、True Peak −1 dBTP以下** に統一。モノラルはブラウザーの左右同時再生に合わせて dual-mono として測定する。
- 音量を測定してゲインを調整し、上限を超えるピークだけを192 kHzで処理するリミッターで抑える。リミッター遅延は補償する。
- 400 ms未満の短いセリフも測定できるよう、測定・処理時だけ末尾に1秒の無音を足す。納品WAVは元と同じサンプル数・サンプルレート・チャンネル数・PCM16に戻し、再生時間を変えない。
- 処理後の25本は −12.26〜−11.86 LUFS、最大True Peak −1.09 dBTP。空の押し順は処理前より約4.4〜6.7 LU上がり、キャラ間・セリフ間の音量差を抑えた。
- 提供原本には変更を加えない。処理前のゲーム用コピーも別フォルダーへ退避し、Gitの処理前コミットと各ファイルのSHA-256を記録する。素材はユーザー提供の著作物として扱い、学習には使用しない。

測定値・元ファイルと出力のSHA-256は `docs/character-voice-normalization.json`。再生成スクリプトは `scripts/normalize-character-voices.mjs`（Node.js、FFmpeg、FFprobeが必要）。出力先は存在しない新しいフォルダーを指定する。

```powershell
node scripts/normalize-character-voices.mjs --source-dir <原音をassets配下の構造で保存したフォルダー> --output-dir <新規出力フォルダー>
```

新キャラだけ処理する場合は `--only toto` のように登録パスの文字列で絞る。PCM16/24の原音に対応し、ゲーム用出力はPCM16。

追加キャラも同じ基準を使う。二重処理を避けるため、ノーマライズ済み音源ではなく原音から作る。検証を通った出力をゲーム用assetsへコピーする。再生時のキャラ別追加ゲインはなく、全キャラ共通のボイス音量・マスター・ミュートを引き続き使う。BGM・効果音・保存済みスライダー値は変更しない。

検証: 共通カテゴリ・再生中の変更・マスター・ミュート・効果音との独立性・確定ボイスのフェードを `tests/nova-voice-volume.test.mjs` で確認。
