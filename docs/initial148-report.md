# 初期pt200・くしゅり／にと・7揃い100pt（v148）

2026-09-28。初当たりは平均200ptへ変更。とと・空・裏空は5G制を維持し、ネビュラによる5Gリセット率で差を付ける。

## 初当たり

AT当選BIG終了後の準備3G → 赤777 → ルーレット → くしゅり／にとの初期ゾーン3G → AT。直撃などの初当たりも同じ入口を使う。2人の選択率は各50%、性能は共通。

毎Gは＋50ptが2/3、＋100ptが1/3。合計150～300pt、平均200pt。固定200ptに追加で200ptを付与する意味ではなく、この3Gの合計だけをAT初期残りptへ一度加算する。準備・ゾーン中のベル払い出しとBETは別。

| 合計初期pt | 確率 |
| --- | ---: |
| 150 | 8/27 = 29.63% |
| 200 | 12/27 = 44.44% |
| 250 | 6/27 = 22.22% |
| 300 | 1/27 = 3.70% |

従来の「初当たりで内部決定」の仕組みを維持し、上表で先に合計を抽選。100ptの回数を決め、3Gの順番を一様にシャッフルする。これは毎G独立の50/100pt抽選と同じ同時分布になる。合計・演出計画・消化位置を保存し、再読込でも引き直さない。各停止で既存の＋50／＋100pt表示と上乗せSEを使用する。

新規初期ルーレットは2人のみ。くしゅり＝ピンク髪、にと＝茶髪・白い帽子。対応ランプ点灯とキャラ別リザルトに、提供PNGを無加工で表示。通常特化の9種類、CZの6段階、通常リザルトの設定示唆抽選には2人を加えない。

保存済みの旧初期ゾーンは、待機中・抽選済みを含め旧quotaと5G演出を保持。通常AT中の残りpt、確保済み上乗せ、ストックを削らない。復帰や引き戻しでは初期ptを再抽選しない。

## とと・空・裏空

7揃いは全て＋100pt。ネビュラは従来どおり＋10ptと残り5Gへのリセット。最終Gでもリセットする。

| ゾーン | 自然7揃い／G | ネビュラ／G | 5G中に1回以上リセット | 最低保証 | 平均上乗せpt |
| --- | ---: | ---: | ---: | --- | ---: |
| とと | 35% | 2% | 9.61% | 7揃い1回＝100pt | 197.51 |
| 空 | 35% | 15% | 55.63% | 7揃い2回＝200pt | 331.40 |
| 裏空 | 35% | 30% | 83.19% | 500pt以上 | 799.60 |

リセット率は今回の仮配分。5G中の数値は `1-(1-p)^5` で、1Gごとの当選率とは異なる。最低保証は残りGが足りなくなる時点で非ネビュラを7揃いへ書き換えるため、実際の7揃い率は35%より高くなる。裏空の旧途中セーブで残り1G・確保0ptなどの場合は、100ptずつの保証Gを追加して500ptまで継続する。

狙えの青20%・赤80%・虹100%の期待度を維持するため、色の選択率を各ゾーンの当選率から計算する。保証成立は虹へ書き換える。逆押し・第三停止時の成否演出、ボイス・動画の扱いは既存どおり。

平均ptは保証と全ネビュラリセットを含むゾーン単体の上乗せ期待値。消化中の小役払い出し・BET、後続ATの上乗せは含めない。設定差は付けていない。
