# ベース30G・純増4.5／7を固定した勝率優先の調整

2026-10-07。優先目標は設定1〜6の勝率15／20／30／45／60／70%。試作の確率と影響を提示後、「反映」の承認により本番へ採用。

## 固定条件と試算方法

- 通常・通常高確・CZ前兆：全設定30G／50pt。通常ベルナビも含む小役の理論ベース。
- AT消化の純増：全設定共通、通常4.5pt/G・上位7pt/G。特化や準備を含めたAT全体の平均ではない。
- 初期ptは全設定共通の基本300pt＋レア役増加。新たな設定差は付けない。
- 毎BET3pt・リプレイ3pt払い戻し・残ATpt＝手取りを維持。再開待ちは追加しない。
- 設定4は1,000試行、ほかは各500試行。最大50,000G。開始時から差枚＋10,000ptか、最低差枚から＋15,000pt（MY）の先着で停止。
- 勝率は終了差枚がプラスの割合。万pt到達率は開始時から＋10,000pt以上に到達した割合。MYだけによる停止とは別。未消化pt・ストックを最終差枚へ加えない。

## 設定5・6のプラス差枚抑制

- ATの弱役特化抽選：差枚＋3,000ptから抑制開始、＋6,500ptで設定5は50%、設定6は30%の係数まで段階的に低下。既存の＋5,000pt以降の係数（設定5は0.64、設定6は1）も掛かる。
- 差枚による減算区間：設定5は＋6,000ptで入り＋4,500pt以下で解除、設定6は＋6,500ptで入り＋5,000pt以下で解除。
- 既存の時間による減算区間の継続時間・移行率は変更していない。時間による減算が残っている場合、差枚条件を下回ってもすべての抑制が解除されるわけではない。
- 抑制するのは今後の抽選。獲得済みpt、ストック、通常のベル払い出しは削らない。設定1〜4のプラス差枚抑制は従来どおり。

割合の区間はWilson法、機械割は試行単位の総和比率に対するデルタ法。500〜1,000回でも数ポイント程度の誤差が残り、目標勝率を毎回保証する仕組みではない。0件の場合も真の到達率0とは断定しない。

- 調整用と確認用の乱数列を分離。確認後に変更した設定は、別の新しい確認用乱数で再試算。最終表の出典・シード・候補はfinal-manifest.jsonに保存。
- 6設定の理論ベース30・純増4.5／7、確率和、CZ／特化確率の範囲を検証。初期pt、共有役テーブル、AT役テーブルの一致も確認。
- 実際の弱役処理を72万回通し、設定確率と特化当選の実測を照合。差枚による減算区間の出入り、正確な残pt精算、コンプリート停止後に追加Gが進まないことを確認。
- シミュレーション前後で候補・本番の各ファイルが変化していないことをハッシュで確認。統合した候補でも18試行を再実行し、保存結果と完全一致した。採用時に本番と試作の確率・抽選結果の一致を再検証。遊技画面の履歴保存機能は変更していない。
- 今回は勝率優先の配分調整。日本の実機検定に適合したという判定ではなく、短期出玉率の全項目を満たす仕様としては扱わない。
