前回の独立検証各1,000試行、各30,000G。表は途中の累計差枚＋10,000ptで停止した集計。機械割＝全試行の実払い出し合計÷実BET合計、勝率＝終了差枚が正の試行割合。上乗せ予約ptは払い出しに含めない。到達率の95%区間は設定5＝7.65〜11.26%、設定6＝16.69〜21.55%。

設定6の勝率70〜75%という希望は未達。設定5の機械割中心値も105〜106%の目標を少し下回る。今回、その数値を再調整せず選択された案を反映した。

設定5は初期に時間減算を引くと、約81.9%が30,000Gを通じてその時間状態から抜けない。負けを確定する制御ではないが、短い前兆のような区間ではなく長期間の抽選状態となる。

## 保存・計数・履歴

- `nova-decrement.js` を本体とシミュレーターで共用。時間移行は独立したxoshiro128**乱数で毎BETに抽選し、初回だけは初期抽選の状態を使用する。
- ボーナス・準備・リプレイ・特化中もBET単位で計数。0G連では進めない。
- `normalState.novaDecrement` に時間状態、差枚状態、独立乱数の続き、進入回数等を保存する。リロードやAUTO切替で引き直さず、設定変更・朝一リセット・データ初期化で新しく抽選する。
- 既存の保存データには、更新後の利用開始時に減算状態を追加する。既存の差枚、AT残りpt、ストックを消さない。
- 差枚はBET直前およびゲーム精算後に観測する。BETだけで一時的に解除境界を下回っても、払い出し確定前に解除しない。ハズレの0pt払い出しでも精算を観測する。
- 遊技履歴に「時間による減算区間へ移行／復帰」「差枚による減算区間へ移行／復帰」と内部状態を記録。JSON／CSVにも含まれる。

## 維持する抽選・権利

獲得済みのAT残りpt・ストック、当選済み前兆、成立役の配当は減算しない。強ノヴァ目のCZ・特化確定、天井、出陣、特化内部、引き戻しのレア役確定、初期pt、小役確率、通常ベルナビ、上位チャレンジの突破率も据え置く。以前からある累計差枚＋2,400ptチャレンジの残りpt・ストックリセットは、その既存ルールとして継続する。
