# 初期ptゾーンのキャラ制限（v147）

初期pt獲得専用の宗介・ギル・裏ギルは、通常シャッターの既存pt画像に対応する額だけで選択する。現在の初期抽選300〜1,200ptの範囲では300・500・1,000ptが対象。

- 初期ptを先に一度だけ抽選する仕組み、19段階の振分、平均750pt、待機3G・初期ゾーン5Gは維持。
- 対象外のptでは3キャラの選択ウェイトを0にし、他キャラのウェイト比を保って抽選。ルーレットの途中表示にも対象外キャラを含めない。
- 宗介・ギル・裏ギルの初期5段階は、各累計を既存ptの範囲へ切り下げる。最終額は抽選済みptに必ず一致する。同額の段階は従来どおり通過演出を使う。通常特化ゾーンのテーブル自体を変更するものではない。
- 確保額・段階一覧・シャッターをすべて既存画像で表示し、画像生成や素材加工は行わない。
- 初期ゾーン開始前の旧セーブで対象外キャラが予約済みなら、宗介→とと、ギル→空、裏ギル→裏空へ一度だけ移す。既に進行中の初期ゾーンは保存された演出計画と確保額を保持し、途中でキャラを変更しない。
- 通常AT中の特化ゾーン、追加ストックの確率、ボーナス初回AT当選率は変更しない。

## 検証

全設定・全19初期ptの候補とウェイト境界、3キャラ×3対象pt×40乱数系列の既存画像・最終獲得一致、保存復元、通常特化との分離、ルーレットのランプ表示を確認。既存の初期ゾーン・AUTO・ボーナスストック関連を合わせ34テストが成功。

全6設定で各30,000G、計180,000Gの進行確認も完了。これは停止・例外の確認であり、機械割の推定ではない。

## 機械割の扱い

初期ptの抽選分布そのものは変更していない。ただし初期ゾーンのキャラ構成が変わり、宗介・ギル系で発生していた途中のベル払い出し・リプレイ頻度も全体では変わるため、v146の機械割を現仕様の検証済み値としては扱わない。表示用の値と根拠は変更前の記録として保持。通常時の当選率などを今回の表示修正に合わせて再調整することはしていない。
