# 押下位置によるリール停止制御（2026-10-28）

- 通常の停止では押下時点の位置を記録し、成立する停止形のうち近いものへ停止する。
- ハズレ・1枚役・手打ちのレア役は4コマ以内。後続リールでも停止可能な形を選ぶ。
- ベル（8pt・15pt）とリプレイは取りこぼさず、必要時のみ4コマを超える。
- 手打ちのレア役取りこぼしは払い出しを0ptにする。内部成立役、CZ・BB・AT等の抽選結果やストックは変更しない。
- AUTO・超ハイスピードではレア役を取りこぼさない。手打ちで取りこぼし確定後にAUTOへ移行しても払い出しは復活しない。
- 狙え演出・特化ゾーンの専用停止制御・逆回転は既存の確定停止形を維持する。
- 停止途中の保存では停止済み列と取りこぼし判定を保持する。変更前の回転途中セーブには旧制御を適用し、次回BETから新制御となる。

公開機械割の試算は取りこぼしのない条件。手打ちの実績機械割は、取りこぼした払い出しにより低下する。人の押下タイミングは未測定のため低下幅は固定値では示さない。
