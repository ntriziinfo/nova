# CZ全灯の高速七色点滅・レア役ナビ効果音

2026-09-28

- CZの逢魔ランプ（8人目）点灯時、全員が同期した七色点滅へ切り替わる。色は0.7秒周期、明滅は0.24秒周期。既存のCZ虹告知も同じ表示を使う。
- 通常のボーナス虹発光は従来の速度。CZ終了後は通常表示へ戻る。OSの動きを減らす設定では静止発光。
- レア役ナビが出るBETで `rare-navi.mp3` を1回再生。緑・紫・赤の「！」「！！」共通、手動とAUTO共通。キャラのチャンスボイスは既存どおり併用。
- 音源は提供された「レア役.mp3」を無加工で使用（2.046145秒、44.1kHz、ステレオ、84,635 bytes）。効果音カテゴリ、ループなし。原本とコピーのSHA-256一致。学習用途には使用しない。
