# 小役CZ当選後のリール消灯前兆（v152）

追記：v158で「消灯をBETで解除し、1回転の全消灯で確定」へ変更。以下は旧仕様の記録。現行仕様は [prelude158-report.md](prelude158-report.md) を参照。

小役でCZ／強CZに当選したゲームではCZへ即移行せず、当選の次ゲームから3〜10G（各長さを均等選択）のCZ前兆を消化する。天井の突破確定CZにも同じ消灯前兆を使い、天井BIGの既存前兆は維持する。

- 前兆中は通常の小役・払い出し・再遊技を処理する。前兆G数はCZの残りG数に含めない。
- 消灯は前兆の進行に合わせて左→中→右。各ゲームの第三停止で図柄が停止した後に段階を更新し、BETや停止ボタン押下時点で先に全消灯させない。
- 最終前兆Gで3リール全消灯し、内部的にCZへ移行する。このゲームではCZ告知を出さない。
- 次のBETで消灯を解除して「CZ突入／強CZ突入」を一度だけ告知。そのゲームがCZの1G目となり、キャラランプ抽選と残りG数の消化を行う。
- 前兆の残りG数・消灯段階・強CZの突破率・告知待ちを保存し、再読み込み後も再開する。
- 前兆中の再当選で前兆を延長しない。強ノヴァ目による強CZ昇格は残りG数を維持し、既存の高確100%／低確85%を引き継ぐ。フリーズ・スーパーノヴァ目のボーナス優先時は前兆を解消する。
- 旧保存データの当選済み前兆は互換処理で消化。デバッグの「CZ突入／強CZ突入」直指定は従来の即移行を維持する。

検証: 最短3Gから最長10Gまでの全長さ、第三停止と次BETの区別、CZ1G目の消化、保存復元、天井、強CZ突破率、強ノヴァ昇格、プレミア優先を確認。実ブラウザーをミュートし、小役当選→前兆→全消灯→再読み込み→AUTOで次BET告知→CZランプ点灯・残りG数減算を確認。新規のブラウザー実行エラーなし。

関連テスト26件中24件成功。残る2件は旧AT初期150ptを期待する既存テストで、変更前の `98d1710` でも同じ値で失敗することを確認済み。今回の変更で新たに失敗したテストはない。

共有モデルでも全6設定それぞれ30,000Gを完走し、CZ突入・CZ成功・AT移行まで進行することを確認した。これは進行確認であり、機械割の再校正ではない。

CZ当選率・突破率・上乗せ確率は再調整していない。前兆ぶん通常Gが増えるため、従来の機械割・CZ出現率の試算値はそのまま流用しない。
