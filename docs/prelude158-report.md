# 1回転内の消灯前兆・AT前兆・レア役ボイス（v158）

2026-09-28

## 消灯と告知

- 消灯を次ゲームへ持ち越さず、BETで3リールとも復帰。消灯対象は固定の左→中→右ではなく、実際に停止したリール。
- 通常CZ前兆は契機ゲームを含む3〜10G。途中は毎G第一停止または第二停止まで消灯し、最終Gだけ第一・第二・第三停止の全リールが消灯してCZ確定。次BETでCZ／強CZを告知する。
- 消灯する停止では、通常の停止音に代えて `assets/media/jag/cz_third_failure.wav` を再生。提供済み `CZ3失敗.wav` とSHA-256が一致する既存ファイルを使用。消灯しない停止は従来の停止音。
- 停止完了に合わせて暗転。全停止後の結果処理では消灯音・消灯処理を繰り返さない。

## AT中

- 特化ゾーン当選の告知だけを遅らせる。直乗せは従来どおり成立ゲームで表示・加算。
- 通常AT中のレア役から、契機ゲームを含め3／4／5Gの前兆を均等に選択。特化非当選でも前兆に入り、途中は毎G1〜2リール消灯する。
- 当選時は最終Gの3リール全消灯で特化確定、次BETで7狙えへ。非当選時は最終Gで消灯せず前兆終了。
- 前兆中も既存の小役・直乗せ・特化ゾーン・裏チャレンジ抽選を処理。追加のゾーン当選は保持し、前兆期間を延長せず先の当選と合わせて消化する。
- 残りptが0になっても前兆の当否告知を完了してから次状態へ進む。ボーナス特化ストック・裏チャレンジ待機が前兆を横取りしない。途中セーブから再開可能。
- 小役確率・直乗せ当選率・特化当選率そのものは変更しない。前兆追加・通常CZ前兆の数え方変更に伴うゲーム数と出玉への影響はあるため、機械割が同一であるとは扱わない。今回、機械割の再試算・調整は未実施。

## ボイス

- 逢魔・裏逢魔を含む全特化ゾーン、初期ptゾーン、特化入口の抽選中は、チャンス／大チャンス／激熱ボイスの対象外。既存の専用狙え・成立・継続ボイスは維持。
- 通常ATの「大チャンス」は実際の直乗せ当選時のみ。特化当選がある場合は従来の「激熱」を優先し、当選を保持した前兆中も対応する。
- 通常時の「大チャンス」は成立役と成立前の内部状態・設定から計算したCZ抽選率60%以上の場合。未確定の通常役や低期待度役を、結果だけを見て60%と表示する方式ではない。既にCZ予約がある前兆中は100%として扱う。
- それ以外のレア役告知は「チャンス」。音量とキャラ抽選は従来の共通ボイス設定。
