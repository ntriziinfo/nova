# 保存復旧と複数タブの修正（2026-10-01）

## 変更

- 共通設定・通常保存・復帰用保存を個別に検証する。一部のJSONが破損していても正常な保存から復帰し、残りpt・ストック・停止途中の確定済み抽選を保持する。
- 両方の遊技保存が復旧不能、または復旧処理自体が失敗した場合は、元データを上書きせず遊技を停止して案内を出す。保存データの自動削除はしない。
- Web Locksで同じ保存先を使用するタブの起動を排他制御する。2つ目のタブは保存・管理操作・遊技を開始しない。先のタブを閉じた後に再読み込みすれば再開できる。
- 所有権はバックグラウンドでも維持する。タイマーによる期限切れは使用しない。ページを離れる際は最終保存後に解放し、ブラウザ履歴から戻った場合は保存を読み直す。
- Web Locksが使えない環境では保護なしで起動せず、最新ブラウザとHTTPS公開ページの利用を案内する。排他制御の対象は同じブラウザ・同じオリジン・同じ台／遊技セッションの保存先。
- 管理画面からの設定変更も共通の保存処理を使用する。日時・停止途中の状態・予備保存・設定を保存し、失敗時は既存の保存エラーを表示する。

抽選確率、払い出し、上乗せ性能、獲得済みptとストックの仕様は変更していない。

## 確認

- 破損した共通設定／本保存／予備保存の各ケースを検証。正常なコピーから残り850pt・ストック2個・未精算の回転を復旧。
- 全コピー破損、復旧処理の例外では元データが不変。
- 管理設定変更後の通常保存・予備保存・共通設定が一致し、終了イベントなしの復帰でも変更と未精算の回転を保持。
- 同じ保存先の同時起動、異なる保存先の独立起動、所有権解放後の起動、所有権取得前の終了を検証。
- 実ブラウザで二重起動の案内、予備保存から123G・払い出し3456ptの復元、全コピー破損時の停止と元データ保持を確認。
- 所有タブから離れた後、待機タブの再読み込みで起動できることを実ブラウザで確認。全503件のテスト成功、関連26件の再確認、構文・参照先・公開ルートの検査成功。
- 既存のフリーズのテストで省略されていた乱数引数を固定。検証対象外の初当たりチャレンジへ偶然分岐する不安定さを除去。製品の乱数処理は変更していない。

更新前のページは新しい排他制御を持たないため、更新時は開いているNOVAのタブをすべて閉じ、開き直すこと。
