# 裏ギル：テーブル⑥固定・300pt通過保証

裏ギルの新規突入は設定・突入経路を問わず⑥（300→500→1000→2000→3000pt）固定。
300pt以下の確保段階では小役を保証。⑥の初回抽選300→500ptは通過確定。
500pt以降は標準成功率2/3を維持。ゾーン選択率は変更しない。
保存済みの進行中テーブルは保持し、次回の裏ギル突入から⑥固定になる。
