# CZ集結ゾーンのBGM

通常CZ・強CZとも、CZ確定後の1G目BETで集結ゾーンの動画が始まるときに `audiostock_932814.mp3` へ切り替える。前兆の全消灯・CZ確定の停止時点では通常BGMを維持する。

音源は既存のBGM音量で一度だけ再生し、終了後は通常BGMへ戻す。2G目以降のBET・音量変更・再読み込みで再生済みの音源を再開しない。CZ終了・ボーナス移行では既存のBGM切り替え処理に従う。初回BETの途中保存を復元し、音源がまだ終了していない場合はCZ用音源を選択する（ブラウザが再読み込み直後の自動再生を制限した場合、次のBETで再生を再試行する）。
