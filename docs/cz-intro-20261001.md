# CZ 1G目の集結ゾーン告知

通常CZ・強CZの1G目のBETで、ランプ欄（7狙えと同じ領域）に `bg_09.mp4` と添付の「NOVA Familia 集結ゾーン」画像を重ねて表示する。動画はミュート・ループ、画像は縦横比を維持して中央表示。既存CZのBGMと音量設定を使う。第三停止後も表示し、次のBETで終了する。

1G目はキャラ点灯・七色点灯・点灯SEだけを抑える。抽選、CZ残りG、払い出し、書き換え、1G目で成立したボーナスは従来どおり。2G目以降は元の累積点灯予定を使用する。ガセ前兆・CZ前兆の途中では告知画像を出さない。初回BET中の再読み込みでも既存の回転復元から告知を復元し、追加BETや再抽選をしない。

原本を無変換でコピーし、SHA-256一致を確認した。
