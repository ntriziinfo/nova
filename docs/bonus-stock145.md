# ボーナス追加ストック → 上乗せ特化ゾーン（v145）

- 通常時BIGの最初のAT獲得は従来どおり。準備3G → 赤7 → ルーレット → 初期pt決定ゾーンを経由する。初期ptの分布は300〜1,200pt、50pt刻み、平均750pt。
- AT獲得後のボーナス追加当選、および既存AT中のボーナス当選分は、1個につき通常の上乗せ特化ゾーンを1回ストックする。固定150ptは加算しない。
- ボーナス終了後、初期pt決定や進行中の演出・予約済みゾーンの終了を待ち、BETで1個ずつ消化する。赤7揃い → ルーレット → 特化ゾーン。通常ATの残りptは減算しない。
- 特化振分は通常ATと共通：弱特化70%、強特化29.1%、裏特化0.9%。各グループ内は3キャラ均等。ルーレット中のレア役昇格も通常どおり。
- 各ゾーンでは通常の上乗せ抽選を行い、そこで獲得したptだけをAT残りptに加える。複数ストックは順に消化し、残りptを持ったATへ復帰する。
- 保存データの `sets` は特化ストック数として継続使用する。未消化の旧150pt／300ptストックも個数を保持して特化ゾーンへ置き換える。既に加算・獲得したptは変更しない。
- 表示・履歴を「特化ストック」に統一。試算モデルも同じコア処理を使い、未消化ストックを150ptとして残高に加える集計を削除した。

機械割・1万pt到達率はこの変更後の値を未集計。既存の測定値は引き続き変更前の参考値。

検証：ボーナス・初期pt・引き戻し・AUTO・履歴の関連49テスト、HTML構文・配信設定チェックに合格。全設定で各30,000G（xoshiro128、seed 145001〜145006、コンプリート停止なし）の進行確認を完了。この各1試行は進行確認用で、機械割推定としては扱わない。
