# 最寄り小役停止・750ms回転

- 各リール20コマ。ベル・リプレイを増設し、7、BAR、スイカ、nebula、ノヴァ3連を維持。
- 中リールはベル・リプレイを交換した並びを使用。特殊図柄成立時に上下で別役が揃うことを防ぐ。
- ベル・リプレイの停止は固定された上下3図柄の組ではなく、その当選役だけが成立する停止候補から進行方向で最寄りの組を選ぶ。
- 停止要求時に選択列を予約する。以後のリールは予約済みの列と両立する候補だけを使い、当選役を維持する。
- その他の役は既存の停止図柄を維持。図柄帯を差し替えず、回転方向に沿って等速で到達する。
- 正回転・逆回転とも1周750ms。抽選確率・払い出しは変更しない。
