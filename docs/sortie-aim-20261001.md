# ノヴァ出陣チャレンジの逆押し演出

- 出陣中は毎G、右→中→左の順にノヴァ図柄を狙う。AUTO・全停止もこの順序を使用する。
- 停止したリールだけ、逢魔フリーズと同じ停止位置の揺れを継続し、次のBETで解除する。
- 内部ストック当選かつ正しい押し順なら全リールのノヴァが揃う。非当選では左をノヴァ位置で一度停止し、1段下へずらす。
- 押し順を無視した場合も左を1段ずらしてノヴァ不揃いにする。内部当選した特化ストックはそのまま獲得する。
- ベル・レア役の通常ナビと対応音声は出陣中だけ表示・再生を抑える。既存のナビ・ボイス選択に伴う乱数消費は維持する。
- 内部小役、払い出し、出陣のストック抽選・保証、ゾーン選択、残りATptは変更しない。表示図柄と内部小役は履歴上でも区別する。
- 途中再読み込みは既存の押し順・停止列の保存を使い、停止済みリールの揺れも復元する。リセット時は左リールのずれ演出を取り消す。

検証：関連テスト63件、構文・設定検査、配信素材313点を確認。無音の独立ブラウザで逆押し当選、押し順ミス2種、非当選、途中再読み込み、スマホ表示とAUTO引き継ぎを確認。ストック数・払い出し・残りptが表示操作で変わらず、ブラウザエラーも発生しないことを確認した。
