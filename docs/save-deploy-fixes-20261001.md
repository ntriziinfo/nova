# 保存・表示・配信の修正（2026-10-01）

## 変更

- 遊技状態の保存成功は、完全データまたは再開用データが書き込めた場合に限る。共通設定だけの保存成功で代用しない。
- 保存失敗時には消えない警告と再保存ボタンを表示し、回復時に消す。遊技状態は保存できて共通設定のみ失敗した場合も区別して知らせる。
- CZ・通常・AT設定の保存ボタンも失敗時に成功表示を出さない。
- 標準の抽選設定・コンプリート条件に一致しない場合、標準機械割の代わりに「未試算（独自設定）」を表示する。確率設定を保存した時点で切り替え、標準に戻すと試算値へ戻す。音量・AUTO速度・表示名の変更は対象外。
- 管理画面の純増4pt/G・旧試算説明、READMEの現行v173参照を現仕様へ更新。
- Git LFSの利用枠超過に対応する素材復元ビルドを追加。[配信手順](deployment-assets.md)に素材更新時の運用を記録。

## 確認

- 全495件成功。失敗・skip・TODOなし。全設定30,000Gの承認済みダイジェストも一致。
- 完全保存・再開用保存・共通設定だけ保存・全保存失敗・再保存成功を検査。獲得済みptとストックが維持され、保存処理で乱数を消費しないことを確認。
- 独自CZ・通常・AT設定、コンプリート条件、音量等の表示設定で機械割表示を検査。
- 無音の独立ブラウザでCZ率40→41を保存すると「未試算」に切り替わり、40へ戻すと標準試算値へ戻ることを確認。
- 同ブラウザのテスト用保存領域を実際に満杯にし、BET時の保存失敗の警告を確認。テスト用データを取り除き再保存すると警告が消え、回転中の状態も保存された。
- 配信用素材311ファイルとアーカイブのSHA-256を検証。欠損・変更されたLFSポインタ、破損素材、危険なパスを検査。

抽選確率・払い出し・上乗せ・初期pt配分・出玉補正は変更していない。イラスト・音声・動画の内容も変更していない。
