## 共通の進行

- 出陣は総ゲームで奇数1/7,000、偶数1/10,000。10Gで毎Gストック抽選、
  最低2ストック。設定5・6は大量ストックと裏ゾーン振り分けを抑える。
- 初当たりの5%は上位ATチャレンジへ移行し、成功期待度50%。
  レア役契機と累計差枚＋2,400ptごとのチャレンジは65%。
- 10Gのチャレンジではベル・リプレイ・レア役はHOLDし、次Gでノヴァを狙う。
  レア役は成功確定。上位ATは直乗せ／弱ノヴァ特化抽選が通常の1.5倍。
- 差枚契機では開始時に残りpt・未消化ストックを消去。成否とも特化1個で
  再開し、失敗時は通常AT、成功時は上位ATとなる。上位中も再挑戦する。
- ＋2,400／4,800／7,200…の消化済み到達点と出陣予約は台ごとに保存する。
  既存の保存データは過去の最高差枚より次の到達点へ移行し、過去分を遡及発動しない。
- 旧版の図柄・音声・ランプ配置を維持し、手動・AUTO・高速試打に共通の抽選を使用する。
