# 分散型チャレンジとBIG・AT配分（v120）

判定：**全設定で機械割・到達率の両方が採用範囲内**。各設定30,000G×3,000試行。

## 変更内容

BIGは50pt、初期ATは300pt。BIG突破は通常52%・上位80%を維持。通常・CZのコイン持ちは50ptで約38.5G。通常レア役、AT各レベルの小役・上乗せ性能、特化9種の保証と抽選は維持。差枚による調整・通常ATの強制上限は設けない。

チャレンジは1AT中1回まで、3G合算50%で成功。発生時にpt型70.00%／裏ゾーン型30.00%へ分岐する。

- pt型成功時：500pt＝60.00%、1,000pt＝30.00%、2,000pt＝10.00%。
- ptと独立にレベル抽選：昇格なし＝60.00%、Lv.4＝25.00%、Lv.5＝15.00%。現在のレベルより下がらない。
- 裏型成功時：裏ギル・裏空・裏逢魔を各1/3で獲得。pt直接加算・レベル昇格はなく、選ばれた特化での獲得結果を加算する。
- 両タイプを試せる一度きりの強制フラグをデバッグに追加。成功・失敗は通常の50%抽選。

## 測定条件

機械割は実払い出し÷実BET。リプレイ後のBETは無料。差枚＋10,000pt初回到達で停止し、未到達は30,000Gで打ち切る。到達率はその30,000G内の差枚＋10,000pt到達割合で、累計払い出しではない。未消化ptを出玉に先取りしない。特殊モード・設定別初期穢れから開始し、正しいナビ操作を仮定する。

独立した検証シードを使用し、各設定の全試行を集計。機械割±0.5ポイント、到達率は設定1±0.75／設定2・3±1.0／設定4～6±1.5ポイントが採用範囲。95%区間は有限試行の不確実性を示す。ゲームコアによる試算であり、実機検定への適合を示すものではない。

初回の独立検証で設定2・3・4の停止込み機械割が範囲外だったため、設定別の初当たり補正を修正し、設定3はチャレンジ係数も調整して、別シードで各3,000試行を再検証した。変更していない設定1・5・6は最初の検証を採用。各設定の全試行を集計し、修正前のデータを最終値へ混ぜない。
