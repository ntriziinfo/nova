# 裏ゾーン調整・3区分抽選（2026-09-08）

裏選択率は従来の「強ゾーン選択後3%」を維持。全体2%案は採用しない。
弱＝宗介・とと・うらぴ、強＝ギル・空・逢魔、超＝裏ギル・裏空・裏逢魔。各区分内は3種均等の仮設定。
通常のゾーン抽選は従来の弱／強合計比率（設定差、高確補正を含む）を維持し、強の3%を超へ振り分ける。準備中は従来の準備中比率を使用する。穢れ・フリーズは既存の最低ランクを保ち、強を選んだ場合だけ3%で対応する裏へ昇格。確定したゾーンは開始時に再抽選しない。

|変更|変更前|変更後|
|---|---|---|
|裏逢魔・通常／フリーズ中の揃い|50／100pt|100／200pt|
|裏空 nebula リセット率|12%|25%|
|裏空 7揃い率|65%|65%|

「空を裏ギルに合わせる」は裏3種の平均を揃える意図として、裏空を調整。通常の空は変更しない。

平均はゾーンの上乗せのみで、通常払い出しやその後のAT中の抽選は含まない。最低保証額ではない。
通常AT・高確補正なしでの超の全体比率は設定1から順に0.28186%、0.29180%、0.29950%、0.76922%、0.96723%、1.37891%。

抽選の境界、予約から開始までの保持、通常／0G連の倍額、解析平均とシミュレーションの整合をテスト済み。今回の変更後の全体機械割は未再測定。過去の機械割実測は今回の値を保証しない。
