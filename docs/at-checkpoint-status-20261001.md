# AT残ptからの上位ATチャレンジ表示

ランプ上の状態欄を、次の条件で金色の「AT 残り○○pt ＋上位ATチャレンジ」にする。上位AT中は先頭を「上位AT」にする。

- 通常のAT消化中に、現在の累計差枚＋AT残ptが次の未消化トリガー以上。
- 実際に到達済みで差枚トリガーが待機している間も表示する。
- トリガーは保存済みの次回到達点（＋2,400／＋4,800／＋7,200…pt）を参照する。固定の2,400ptとの比較ではない。

例：差枚＋2,000pt・残り500pt・次回＋2,400ptなら表示する。差枚−1,000pt・残り3,000ptなら表示しない。前回＋2,400ptを消化済みで次回＋4,800ptなら、その次回ラインと比較する。

AT残ptは払い出し総数。表示条件には今後のBET消費を含まず、上位ATチャレンジ到達の保証ではない。表示条件を下回れば通常色・通常文言へ戻す。未消化ストックの期待値・特化中の未加算ptは足さない。

特化・初期pt決定・ルーレット・前兆・出陣・引き戻し・チャレンジ中は、進行案内を優先する。BIG中、ボーナス準備中、リザルト、コンプリート中も通常の案内を維持する。

表示判定は状態の読み取りだけで、乱数・抽選・払い出し・トリガー予約・残ptやストックのリセット処理を変更しない。1ptベル案も取り込まない。

確認：関連テスト12件、構文・設定・素材検査を通過。無音のブラウザで境界値、マイナス差枚、次回ライン、上位AT、到達待機、チャレンジ中、特化中、再読み込み、AUTO、390px幅の表示を確認。記録は `research/at-checkpoint-status-20261001/`。
