表は規定G到達時のCZ当選率。非当選時50%でガセ前兆。前兆3〜8Gを均等選択。非当選・ガセ非選択では何も発生しない。CZ中の到達は前兆を予約し、CZ失敗後に進行。ボーナス成立で予約は消去。
小役CZ当選は通常前兆より優先し予約を消費。天井前兆中は天井恩恵を優先。ガセ前兆終了では穢れを加算しない。
天井到達時にBIG50%／突破確定強CZ50%を選択し、前兆後に告知。突破確定CZのボーナス種別は既存CZ成功時振分。天井穢れ加算は1回のみ。500/600Gは10pt、300Gは5pt、100/200Gは1pt。
通常の高確移行率は全モード共通：弱スイカ5%、強スイカ50%、チャンス目A/B32.143%。10G保証、保証後はハズレ8%・リプレイ5%で転落。
