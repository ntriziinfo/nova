# CZ点灯分散・点灯SE・直乗せ画像切替（2026-09-28）

## CZの点灯

v150の「1G目にくしゅり・にと・宗介を固定点灯」を撤廃。最終点灯人数に応じてCZ全体を分割し、その区間内の第一・第二・第三停止へ点灯を分散する。点灯人数の少ないCZでも、最後の点灯が終盤まで分散する。順番は従来どおり、くしゅり→にと→宗介→とと→うらぴ→ギル→空→逢魔。

CZに保存済みの抽選値から表示専用のシードを導出し、再読み込みでも同じ時刻を使用する。ゲーム抽選の乱数を追加消費しない。途中のレア役で最終点灯人数が昇格しても、既に点灯したキャラを消さない。

最終期待度、CZの当落、レア役書き換え、虹告知、全員点灯でCZが終わるゲーム数は維持。逢魔の点灯は従来の全員点灯確定ゲームの第三停止に合わせる。

## 点灯SE

実際にリールが停止した際の点灯処理で、全キャラ共通の点灯SE `cz_third_success.wav` を再生する。第一・第二停止の点灯にも対応し、同じ停止で複数が同時点灯するときはSEを1回再生する。虹への変化も同じ処理に含める。

第三停止で点灯音をもう一度再生する処理を廃止。第一・第二停止で点灯済みのゲームは、第三停止を通常のCZ停止音にする。CZ最終ゲームのハズレ音と最終停止リールの消灯、当選確定音は維持する。終了処理が再度呼ばれても点灯音を重複させない。停止・点灯音は先読みする。

## 直乗せの数字

再利用しているimgのsrc切替中に以前の画像が見える問題を修正。次の獲得ptを表示する前に以前の画像を非表示にし、新しい画像の復号が完了した場合だけ表示する。読み込み中やエラー時は、今回実際に加算するptをテキスト表示する。

画像要求の番号を照合し、古い読み込みが遅れて完了しても別の獲得ptや消去後の画面へ再表示しない。直乗せの抽選額と実加算は同じ `atOutcome.direct` を参照したままで、加算処理を変更しない。
