# 減算区間＋差枚による移行条件の試作（2026-09-29）

通常時のCZ抽選を重くする減算区間と、AT中の新しい上乗せ抽選の抑制を組み合わせた。時間・抽選だけの区間では＋1万pt率が増えたため、ユーザーの確認後、累計差枚が高いときに入る減算区間も追加して試算した。**当初は未反映の試作。後続の「反映して」により、設定5・6へv170として採用。実装と他設定の比較は `docs/nova-decrement170-release.md` を参照。**

## 試作のルール

- 設定1〜4は変更しない。
- 獲得済みAT残りpt・ストック、当選済み前兆、成立役の配当を削らない。残りptを直接減らす処理もない。
- CZ・ATの新規抽選に係数を掛ける。強ノヴァ目のCZ・特化確定、天井、出陣、特化内部の抽選、引き戻しのレア役確定は維持する。
- 通常ベルナビ、小役確率、初期pt配分、上位チャレンジ突破率は変更しない。
- 時間による減算状態は、毎BETに独立乱数で移行・復帰する。差枚の先読みや勝ち負けを直接決める処理はない。初期状態も定常割合で抽選する。
- 差枚による減算状態は別に保持し、入口に到達したら発動、出口まで差枚が減ったら解除する。時間による減算状態が残っていれば、そちらは継続する。

|区間外の平均滞在G|183,333G|27,000G|

係数はv169からの倍率で、当選確率そのものではない。AT係数は直乗せ・弱ノヴァ目の特化当選率へ適用する。今回の候補では区間外のAT抽選も25%へ下げ、その分をCZ側で補っている。差枚による状態と時間による状態が重なる場合は弱い方を使い、二重に掛けない。

設定5の平均15万Gは、30,000Gの試打より長い。初めに減算状態を引くと約81.9%が30,000Gの間そこから抜けない。短い演出区間というより、リセット時の状態によって長時間の出玉傾向を変える性格が強い。減算状態でも当選するので、負け確定ではない。

## 再現・検証

- 制御無効時、v169の設定4・5と既存の設定6の保存済み30,000Gダイジェストが一致。
- 全試行で30,000G消化、実払い出し−実BET＝差枚、区間進行数＝BET回数を検証。
- 差枚入口の直前／一致、入口と出口の間、出口の一致、マイナス域の状態遷移を確認。
- 差枚状態の移行だけでは獲得済みの残りpt・ストックを変更しない。強ノヴァ目の確定を確認。
- 試算前後で公開用抽選ファイルのハッシュが一致。公開版を変更する操作はしていない。
