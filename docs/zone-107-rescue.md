# 穢れを救済契機へ変更

レア役・100Gごとの加算を撤廃。標準の仮設定は以下。

|契機|加算|
|---|---:|
|CZ最終G失敗|1pt|
|ボーナス終了後AT非突入|2pt|
|初期1セットのみ・直乗せもゾーンもなしでAT終了|2pt|
|99/100G天井|1pt|
|300G天井|5pt|
|600G天井|10pt|
|REG2連目以降の各REG終了|2pt|

REG連続回数はBIGでリセット、ATを挟んでも保持。重複契機は合算、100pt上限。
天井加算は当該ボーナスの穢れ解放判定より前。ボーナス終了時・AT終了時の加算で100ptになった場合は次のボーナスで解放。
朝一の既存振分、100pt解放恩恵、保存済み穢れは維持。進行中の旧ATは履歴不明のため駆け抜け加算対象外。
ボーナスで複数セットを得た場合やAT中に直乗せ・ゾーンを得た場合は駆け抜け対象外。判定履歴とREG連続回数は保存・復元に対応。
管理画面の穢れ加算設定も更新。600G天井値の半分を300G、1割を100G以下へ適用。

機械割・解放頻度は変更後未測定。レア役蓄積の廃止に伴い、以前の機械割測定結果は変更前の記録となる。
