# リプレイ3pt戻し・二重コンプリート上限

リプレイは3ptを払い戻し、次回BETも3ptに変更。ATの手取り残ptとBIGの50pt消化目標を維持。CZ・特化などの確率調整は行っていない。

累計差枚＋10,000ptかMY15,000ptの先着で停止。MYは過去の最低差枚からの回復幅（BET直後を含む）。例：−8,000ptから＋7,000ptでMY到達、−20,000ptから−5,000ptでもMY到達で停止。停止判定までの払い出しは全額加算する。

1万Gを基本の比較条件、5万Gを長時間確認として採用。勝率・万pt率・コンプリート率の分母は各1,000回のリセット試行。機械割は総払い出し÷総BETで、総BET＝消化G×3。未消化分は収益に含めない。比率の統計誤差は1,000回では最大およそ±3.1ポイント（95%）。各設定の区間はJSONに記載。0.0%は今回の1,000回で未観測という意味で、理論上の0%ではない。

旧版はリプレイ後の無料BETを分母に含めなかった。3pt/G換算の数値は会計上の比較で、勝率や差枚が増えたという意味ではない。新旧の本試算は独立シードなので、少差には試算誤差も含む。

以前の勝率15/20/30/45/60/70%等は5万G目標として記録し、今回は目標へ寄せる追加調整を行っていない。

途中セーブの無料BET権利は1回だけ引き継ぐ。既存の累計統計は再計算しないため、更新後にリセットして開始した試行がこの表との比較対象。最低差枚は小さな保存項目として保持し、詳細履歴は増やさない。
