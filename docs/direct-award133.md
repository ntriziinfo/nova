# 直乗せのリール全面表示

AT直乗せがある回転は、第三停止の図柄停止完了時に `atOutcome.direct` に対応する透過PNGをリール3本にまたがって表示する。10 / 20 / 30 / 50 / 100 / 300ptに対応。初期pt・特化ゾーン獲得分やベルの払い出しは対象外。

- 背景・枠なし。220msで拡大表示し、その後は次の有効なBETまで保持。
- 表示と同時に提供音源 `audiostock_266753.wav`（保存名 `assets/media/nova/direct-award.wav`）を1回再生。SE音量に連動。音源は無加工でコピーし、事前読み込みする。
- リールと同じ位置・サイズのCSS変数を参照するため、位置調整・拡縮に追従。
- 従来の「直乗せ＋…pt」の汎用オーバーレイは抑制し、ステータスと履歴の記録は維持。
- AUTOも同じ図柄停止完了処理で表示。次BETで消去。AUTOの待ち時間は変更しない。
- 通常の再読み込み時は表示を復元しない。リセット・SPEED・高速試打の開始時にも消去。
- 抽選、上乗せ額、残りptの計算に変更なし。素材の読み込みに失敗した場合は文字で表示。

検証: `node scripts/check.mjs`、`node scripts/validate-config.mjs`、`node research/direct133/qa.mjs`。ブラウザ検証は隔離した無音のEdgeを使用する。

結果: 全6額の実抽選→手動停止→正しい画像・残りpt加算、第三停止完了前の非表示、リール位置変更・画面サイズ変更への追従、AUTOの連続直乗せと非直乗せ、次BET・初期化での消去、再読込時の非表示を確認。ページエラー・素材欠落なし。`research/direct133/qa.json` に記録。

音源追加後も全6額とAUTOで、文字表示と同一処理内の再生開始、1回のみの再生、ループなし、実際の音声デコード・再生成功、非直乗せ時の非再生を確認（検証音声はミュート）。元WAVとのSHA-256一致を確認済み。
