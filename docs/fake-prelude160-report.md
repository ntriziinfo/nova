# 通常CZのガセ前兆（v160）

2026-09-28

- 通常時はCZに当選したレア役だけがリール消灯前兆へ入っていたため、CZ非当選のレア役の50%でガセ前兆を開始する。全設定共通。既存の小役確率・CZ当選率は変更しない。
- 本前兆と同じく契機ゲームを含む3〜10Gを均等に選択。毎GのBETで消灯を解除し、途中は第一／第二停止まで消灯する。ガセの最終Gは消灯せず終了し、CZへ移行しない。
- ガセ中も毎Gの小役・高確移行・CZ・プレミア抽選を続ける。CZ当選時は残りG数を引き継いで本前兆へ昇格し、最後の3リール全消灯→次BETのCZ告知へ進む。強ノヴァ目は強CZへ昇格。非当選のレア役で残りG数を延長しない。
- ガセ中に800G天井へ到達した場合は天井処理を優先する。ガセによる天井延期・穢れの重複加算はしない。BIGやAT終了時には前兆を解消する。
- ガセの保存・再読込に対応。ガセ中のレア役ボイス判定には実際のCZ当選率を使い、予約済み当選として100%扱いしない。監査ログへ通常前兆ルールも記録する。
- AT中は既存の3〜5Gガセ前兆を維持。特化非当選なら最終Gで消灯が途切れ、前兆中に特化当選した場合は全消灯で確定する。
- 旧モードの規定Gによるガセ前兆は復活させない。`gameZoneConfig.fakeRate` は廃止済みの規定G仕様で、今回のレア役ガセ前兆率は `czPreludeRules.fakeOnMissRate`。
