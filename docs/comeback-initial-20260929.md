# 引き戻し後の初期pt決定状態の持ち越し修正

## 修正

初期pt決定の途中でデバッグのCOMEBACKを実行すると、引き戻し状態に initialStage が残った。wait は準備へ戻り、entry は当選したキャラをくしゅり＆にとへ置換し、zone は通常キャラのゾーンへ初期pt用処理を適用していた。実際の nova-game.js の drawNormalResult を使った回帰テストで再現した。ユーザーの観測がこのデバッグ経路だったかは未確認。

引き戻し開始・保存状態の復元時に、初当たり用の段階・待機G・初期配分・消化位置を解消する。当選キャラへ直接入り、そのゾーンで獲得したptからATへ戻る。初当たり用の待機・初期pt決定は維持する。出陣で獲得済みのくしゅり＆にとストック、他の獲得済みストックは削除しない。

公開版の nova-art.js / nova-progress.js / nova-game.js と作業前の本体が一致することを確認した。通常プレイでは既に当選キャラのみの復帰で、初期ptの追加処理はなかった。修正前コミット f1f0f4c と修正後の全設定各30,000G×10シードを比較し、全結果オブジェクトが完全一致した。したがって今回の通常ルートでの機械割低下は確認されていない。
