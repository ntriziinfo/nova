# 上位ATの獲得期待値調整（2026-10-14）

ユーザー承認により、上位に入る頻度を下げ、上位消化中の特化当選を増やす。

- 上位ATのスイカ・弱ノヴァからの特化当選率は従来の1.5倍（通常ATに対する倍率8→12）。
- 初当たりの上位チャレンジ突入は、設定1〜6の順に2.5 / 2.5 / 2 / 2.5 / 2.5 / 1.25%。
- レア役からの上位チャレンジ突入倍率は従来比0.5 / 0.5 / 0.4 / 0.5 / 0.5 / 0.25。
- 差枚2,400ptごとのチャレンジと突破率65%、初当たりチャレンジ突破率50%、通常ATの抽選、直乗せ、特化の配当、純増4.5 / 7ptは維持。
- 直乗せを特化へ振り替える案は別途検討中で、本変更には含めない。

[試算結果](upper-value-20261014.json)は1万G、累計差枚+19,000ptで停止、設定1・2・4・5は各500回、3・6は各1,000回。上位の獲得期待値は1万G以内に開始した上位を通常AT降格・AT終了・コンプリートまで追跡。末尾の追跡は機械割の分母・分子へ含めない。

旧版と試作版に同じシードを使用。機械割差は全設定で95%信頼区間に0を含むが、完全な同値を保証するものではない。変更前エンジンは `tests/fixtures/pre-upper-value-20261014/`、承認済み試作版の代表試行は `tests/fixtures/upper-value-20261014-trials.json` に保存し、現在本体と照合する。
